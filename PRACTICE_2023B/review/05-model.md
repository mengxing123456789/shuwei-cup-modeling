## 2 轴② 稳定性：必须先报不利的一半

### 2.1 **P6** / **P7**：A1 承诺了 σ→10%，但一行都没跑；`L121` 反而把另一种 ±10% 禁了

- `L55`（A1 检验结果）：「只能做敏感性（**σ 提到 10% 看结论是否翻**）」。
- `L121`（C8）：「**禁「±10% 扰动重算」式敏感性**；改用 5% 噪声 MC + 留一」。
- 两句不是同一件事（一个改噪声档位、一个扰动输入），但同一份文档一处说"该做"、一处说"禁做"，读者无法判断哪个口径有效。**而 σ→10% 这个被承诺的检验，在 `code/solve.py` 与任何 JSON 里都找不到执行痕迹**（全树只有 `eps_rel = 0.05` 一处）。

同一件事 `σ` 提一档，把阈值随 σ 线性放大 ⇒ 所有 `span/thr` 一律除以 2。结果（CMD-2 / CMD-7 / CMD-3）：

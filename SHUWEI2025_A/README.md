## 题目

## `COMPARISON_2025A.md` 是本仓库最有价值的一份对标文档

它把「同一模型、两个约定」这件事讲透了：

1. **口径不同，绝对值不可比**：12 篇里有 10 篇的 Q2 无控基线落在 `210.67–245.39`，我们的是 `13148.921`。差异来自两个约定——偏心块算不算附加质量（`M=2800` vs `2000`）、角度以哪条轴为参考（`cos` vs `sin`）。
2. **换成他们的约定就对上**：`M=2000`、`c=1.1c₀` 时 `Q2 = 211.253`，正是 2541225 那篇印出来的数；用 `sin` 读法跑他们的角表，Q1 得 `95.940 → 58.207`（−39.3%），落在他们的 `−38.5% ~ −39.7%` 里。
3. **按降幅排名**：Q2 我们第一（99.93% vs 最好 98.55%）、Q3 第一（99.81% vs 最好 68.88%）、Q1 平手（同口径都是 −39%）。Q2 与 Q3 的成绩来自**训练过的预测器**，不是解析调参。
4. **唯一明显弱处**：Q1 的绝对值（基线 49.320，比他们小得多，因为加了 800 kg 阻尼质量、且 8 Hz 线不在共振点上）——这是把物理算对换来的，必须在论文里说清，否则读者会以为没做出抑制。

**这份文档示范了怎么处理"我的数字和别人差 60 倍"这类质疑：不是辩解，而是把两个约定都跑一遍，证明两端都对得上。**

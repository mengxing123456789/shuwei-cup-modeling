## 1. 骨架：一份能进一等奖的论文长什么样

两份样本的章节顺序几乎一致，差异只在"模型数量"：

| 区块 | 样本 A（2022 国际赛 B） | 样本 B（2026 春季 B） | 作用 |
|---|---|---|---|
| Summary Sheet | 1 页，四段式 | 1 页 | 决定评委第一印象，**逐问回应** |
| Contents | 第 2 页 | 有 | 目录 |
| 1 Introduction | 1.1 Background / 1.2 Restatement / 1.3 Our work | 问题重述与分析 | 背景给 3–5 个数字，重述用**自己的话**压缩，Our work 给路线图 |
| 2 Assumptions | 5–7 条，每条带理由 | 模型假设 | 假设必须**可检验**，后面要有敏感性 |
| 3 Notations | 符号表 | 符号说明 | 一张表，符号与单位齐全 |
| 4 Data | 4.1 数据来源/预处理、4.2 指标构造 | 数据预处理 | **先数据后模型**：清洗规则、缺测处理、单位换算写清 |
| 5–7 主体模型 | 多目标优化(GA/Floyd) → K-means → 博弈 | 三问各 2–4 个子模型 | 每个模型：动机 → 公式 → 求解算法 → 复杂度 → 结果 |
| 8 Sensitivity | 参数扰动、模型对比 | 模型检验与敏感性（OCR一致性/参数/局部/资源/阈值 5 小节） | **一等与二等的最大分水岭** |
| 9 Strengths & Weaknesses | 各 4–5 条 | 模型评价（优缺点/改进/推广） | 缺点要具体到"哪一步近似导致什么偏差" |
| 10 Conclusions | 逐问一条结论 | 结论 | 结论带数字，不重复摘要原句 |
| References | 8–15 条 | 有 | 数据源必须可追溯 |
| Appendix | 代码/推导/大表 | 代码 | 正文不放大段代码 |

**硬指标参考**：正文 20–25 页；图 10–16 张、表 5–10 张、编号公式 12–36 条；每问至少 1 图 1 表。
图多不等于好——样本 A 的 15 张图每张都在正文被引用并给出一句结论。

## 2. 摘要四段式（照抄结构，不照抄内容）

样本 A 的 Summary 骨架：

1. **问题段**（2–3 句）：背景 + 本题要解决什么 + 我们的总体思路（点名模型族）。
2. **模型段**（3–5 句）：Model I / II / III 各一句，写清"用什么方法解决哪一问"，含关键假设或指标定义。
3. **结果段**（4–6 句）：**逐问给数字**，并引用图表编号（"as shown in Figure 3"）。
4. **收尾段**（1–2 句）：敏感性/稳健性一句 + 关键词 3–5 个。

要点：
- 每一问都要在摘要里有**一个可核对的数字**（重现期、趋势斜率、误差、排序第一名）。
- 摘要不出现"本文首先…然后…最后"这种目录式句子，出现的是**方法与结论的因果链**。
- 关键词是检索词，不是标题复述：`extreme precipitation; GEV; Mann–Kendall; return period; urban waterlogging`。

## 3. 建模叙事三件套（每问都按这个写）

1. **为什么是这个模型**：先给数据的性质（样本量、缺失、重尾、非平稳），再说明模型族的选择理由，最后一句"因此我们采用 X，而不是 Y，因为…"。
2. **参数怎么定**：参数来源三分法——数据估计（给公式与估计量）、文献取值（给引用）、情景设定（给敏感性范围）。三者必须在文中标明，不能混。
3. **结果怎么读**：每个结果后面接一句"这意味着…"，并把结果落到题目问的对象上（哪座城市、哪一年、多大损失）。

反面样本（casebook 记录）：2024 C 某篇 `MSE = 0.000100947` 与 `RMSE = 0.008047` 代数不一致（√MSE ≈ 0.010047），
**指标之间必须自洽**，这是查重式硬伤。

## 4. 图表规格

- 图：坐标轴带单位、图例不遮数据、标题写"结论"而不是"变量名"（"Rx1day returns 60-year level in 2021"优于"Rx1day series"）。
- 表：三线表；数字统一有效位；缺测用 `--` 并在表注说明。
- 每图正文引用一次并给结论；每表正文引用一次并给"读表方法"。
- 图号/表号/公式号在摘要与正文中必须对得上（提交前用脚本核对，见第 7 节清单）。

## 5. 检验与敏感性：必做清单

| 检验类型 | 做法 | 我们的对应动作（2021 B） |
|---|---|---|
| 数据源一致性 | 两个独立源交叉比对 | GSOD 附件 vs GHCN 郑州站（已算：日相关 0.678、年总量相关 0.922） |
| 参数敏感性 | 关键参数 ±20% 或网格 | GEV 样本窗口、阈值百分位、CN 值、设计暴雨重现期 |
| 方法对比 | 至少 2 个模型同题对比 + 误差表 | Q3：GEV / 趋势外推 / 树模型，LOOCV 误差表 |
| 稳健性 | 换样本区间/换指标 | 1961–2021 vs 1981–2021 重算趋势 |
| 不确定性 | bootstrap CI 或解析 CI | GEV 参数 bootstrap（1000 次）给重现期 CI |

**敏感性必须有"翻转结论"的勇气**：如果换参数后结论变了，就写"结论对 X 敏感，因此在 Y 条件下应改判"，这比假装稳健更容易得分。

## 6. 常见扣分点（从样本与 casebook 反推）

1. 摘要没有数字，只有"建立了模型并求解"。
2. 假设写了但从不检验（列了 7 条假设，敏感性只做 1 条）。
3. 数据来源只写"来自网络"，没有 URL/机构/时间/单位。
4. 模型堆砌：三个模型各自为战，没有回答同一问的对照关系。
5. 结果与题目问的对象脱节（问"哪些城市"，答"某指数上升"）。
6. 图表与正文数字不一致（改图未改文）。
7. 结论重复摘要；优缺点写"计算量大"这类空话。
8. 页数超限、匿名泄露、页眉缺队号（格式性一票否决项）。

- [ ] 页眉：队号 + 页码；无校名/姓名
- [ ] 12 pt Times New Roman（LaTeX 用 newtxtext/mathptmx）
- [ ] 所有图有编号、图注、单位、正文引用
- [ ] 所有表三线表、表注、正文引用
- [ ] 公式连续编号，正文引用编号
- [ ] 数据源 URL + 访问日期 + 单位换算说明
- [ ] 缺测处理规则写明（阈值、比例、剔除后样本量）
- [ ] 每问都有"结论句"落到题目对象
- [ ] 敏感性 ≥ 3 类（参数/样本/方法）
- [ ] 误差指标自洽（√MSE vs RMSE 核对）
- [ ] 关键数字在摘要/正文/表三处一致（脚本核对）

- [ ] 附录代码可运行、含运行环境
- [ ] 无 "we think/it is obvious" 类模糊表述

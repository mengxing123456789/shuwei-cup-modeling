## 二、AnyMath 是什么（与备赛相关的部分）

来源：官网首页 https://www.anymath.cn/ 与版本页 https://www.anymath.cn/h-col-150.html （访问 2026-11-19）

| 项 | 事实 |
|---|---|
| 定位 | 国产一体化科学计算与工程仿真平台，科学计算 + 框图建模（Simulink 类） |
| 内核 | Julia（官方称大规模 MIMO/OTFS 场景比传统平台快 10 倍以上） |
| 语言 | Julia、Python、MATLAB、Fortran、C/C++ 多语言混合 |
| 建模能力 | 动态建模、物理元件库、状态机、代码生成、可导入 MATLAB/Simulink 模型 |
| 部署 | 在线版（anymath.carila.cn，浏览器即用）、私有化部署、**离线客户端** |
| 离线限制 | 官网明示"支持除免费版外的所有许可证类型"，即离线客户端需激活，不是白嫖通道 |

## 三、对我们这套流水线意味着什么

现有流水线的判据是"每个数字回到 `data/*.json`"（G12）与"同词不许两种算法"（G16），
所以 AnyMath 只能放在**旁路**位置，不能替代主线：

- 主线仍是 Python（`E:\数学建模\数维杯\.venv`）+ LaTeX（MiKTeX）→ 可审计、可复现、可对账。
- AnyMath 的定位：**独立平台的交叉复核**（第二通道），产出框图 + 导出 CSV，
  正文写一句"该水量平衡在 AnyMath（版本号）中独立复现，与 Python 偏差 <0.5%，框图见附录"。
- 这条写法同时满足专项奖条件②"真实采用"与条件③"创新"（跨平台交叉验证本身是方法亮点），
  且不破坏 G12：数字仍从导出的 CSV/JSON 进 `data/`。

## 四、最小可行验证（3 小时，赛前做完）

1. 0:00–0:30 只读三件事：简介 pdf 的目录、基础教程 pdf 的"脚本 cell / 读文件 / 画图"三节。

3. 1:30–2:30 搭框图：降雨输入 → 产流（CN 曲线数）→ 蓄水池（容量）→ 排水/溢流，跑出曲线。
4. 2:30–3:00 导出 CSV 与图，落到 `data/anymath_crosscheck.json`，记录版本号与参数。

判定：3 小时内跑通 → 赛时可用；跑不通 → 降级为"不采用"，不要占用赛程时间。

## 五、红线

- **匿名**：在线项目可能带账号/团队名。截图裁掉顶栏与账号区，导出图不得带水印，论文不写账号。
- **许可**：离线客户端不支持免费版；先验证激活方式，激活不了就走在线版，别在第一天卡住。
- **可复现**：GUI 模型不是文本，附录必须给"框图截图 + 关键参数表 + 版本号 + 导出文件哈希"，否则 S8 可复现维度扣分。
- **时间闸**：只在赛程第一天的建模阶段用；超过 4 小时未跑通立即弃用。
- **主次**：专项奖要求论文本身先拿 F/M/HM，主线做扎实优先于平台加分。

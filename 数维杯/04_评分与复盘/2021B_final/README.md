# 2021 B 题练习（棉秆热解失重模型）

这是 2021 年数维杯 B 题的一次**完整实战演练**：从题面到交稿的全部产物。它验证了 `mathmodeling` 流水线在真实题目上能走完八步，也暴露了一批后来写进 `docs/pitfalls/` 的坑。

## 目录

| 目录 | 内容 |
| --- | --- |
| `2021B_practice_paper.pdf` | 最终练习论文（30 页，2.9 MB） |
| `src/` | 求解代码（65 个脚本：数据清洗、热解动力学拟合、产率预测） |
| `figures/` | 全部图表（30 张） |
| `audit/` | 审读报告（26 份：数字核对、口径审计、格式合规） |
| `results_summary/` | 结果 JSON 小结（11 个；109 MB 的原始结果 CSV 没有入库，重跑 `src/` 可再生成） |

## 与 `PRACTICE_2023B` 的分工

- `PRACTICE_2023B/`（仓库根）是**流水线视角**的练习：测的是八步二十门本身能不能跑通，用的是官方骨架。
- 这里是**题目视角**的练习：测的是拿到一道真实题后从零到成稿的完整流程，用的是当时的自建工程。

两份练习的复盘结论都收在 [`../复盘_2021B.md`](../复盘_2021B.md) 与 [`../自主评分报告_2021B.md`](../自主评分报告_2021B.md)。

## 为什么值得留在仓库

1. **它是 skill 里 `new_paper.py` 的 DONOR 之外第二个可参照物**——一道完整题目的真实产物规模（多少代码、多少图、多少审计报告），对未来估工作量有直接参考价值。
2. `audit/` 里的 26 份报告是「审读小队怎么挑毛病」的真实样本，比 `squads/review/` 的 brief 更具体。
3. 论文 PDF 是「练习水平」的基准线——之后每次比赛后对比，能看出进步在哪。

## 不在仓库里的部分

`results/` 的 75 个大 CSV（109 MB）没有上传——它们是模拟中间产物，`src/` 里每个脚本顶部写了怎么重新生成。原始数据（竞赛给的 xlsx）也在竞赛附件里。

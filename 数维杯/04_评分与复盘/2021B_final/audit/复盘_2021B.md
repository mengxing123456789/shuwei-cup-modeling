## 二、做对了什么（要保留）

1. **先定口径，再跑模型。** Q1 的"2021 年是不是多雨年"必须先决定用 300 天规则还是同窗口比较；Q3 的"预测什么"必须先定 predictand。两次都是口径先动、结论跟着变。
2. **把"目标定义"当成一个可比较的方法维度。** Q3 的十种策略里，真正拉开差距的是"分位数 vs 期望最大值"（RMSE 64.8→55.7，bias −41.5→−20.5），不是分布选择。这条经验可以直接搬到任何预测型题目。
3. **负结果写进论文。** 2021 年郑州日值 188.7 mm 没有破 1978 年的 189.4 mm，五座破纪录城市没有一座在 2021 年——这个负结果反而成了全文最有说服力的一段（日尺度指标看不见小时级灾害）。
4. **多源交叉校验。** GHCN 与 GSOD 在 2021 年 7 月逐日完全一致，日相关 0.6776、年总量相关 0.9217，跨源差异被量化而不是被回避。
5. **隔离纪律执行到位。** 全程没读任何 2021 B 的解答/题解；外部数字只引官方公报与气象学论文，并逐条标 URL。

## 三、踩坑清单（下次别再踩）

| 坑 | 表现 | 根因 | 下次怎么做 |
|---|---|---|---|
| BLAS 崩溃 | 任何 `np.dot`/`lstsq`/`corrcoef` 直接 exit −1066598273，无 traceback | 基础环境 numpy 2.4.6 链接的 BLAS 损坏 | 开工第一件事：跑 3 行 smoke test；坏了就建 venv（本次：numpy 2.2.6 + scipy 1.15.3） |
| Pettitt 假突变 | K=1280、p≈1e-32 | 用了秩和而非符号统计 | 变点检验先用已知无变点序列做 null 校准 |
| SCS-CN 单位 | 体积差 1000 倍 | Mm³ 当 km³ | 所有量纲写进变量名（`_m3`、`_mm`），出数前量纲自检 |
| 期望最大值积分 | 哈尔滨 35.9 mm（荒谬） | 积分只取了上半支 | 用 Gumbel 闭式（ln n + γ）先校验数值积分 |
| 300 天规则砍掉 2021 | 事件年不进入统计 | 规则机械套用 | 事件年允许"同窗口"比较，并在正文说明 |
| 页数攻防 | 34 → 32 → 31 页，来回四轮 | 先写内容后控页 | 写作前就定"正文 20 页预算"，图和表先排队，超了先移附录 |
| 数字与代码脱节 | 损伤函数、1.76e8/8.7h、4/5 vs 1/5、+2.71% | 正文手写公式与数字，没跟脚本对账 | 正文所有公式从代码复制；所有数字由脚本写进 JSON，再自动生成表格 |
| 摘要溢出 | 关键词跑到第 2 页 | 单页硬约束 | 摘要最后写，写完立刻编译看分页；预留 `\enlargethispage` |
| PowerShell 改源码 | 文件被写成含字面 `\n` 的坏行 | 用 `-replace` 改 `.py` | 只用 edit/write 工具改代码 |
| 管道截断 stdout | python 提前 BrokenPipe、exit 1 | `Select-Object -First N` 提前关管道 | 一律 `*> log` 再读日志 |

## 四、流程改造（2026-11-20 直接用）

1. **T+0（开赛 0–2 h）**：读题 → 三问筛题（数据是否拿得到、模型是否有把握、故事是否讲得通）→ 定题 → 建目录骨架（`00_problem/01_code/02_figures/03_results/04_paper/05_audit`）。
2. **T+2–8 h**：数据审计先行。写 `audit_*.csv`（覆盖、缺测、极值、跨源一致性），把"能不能用"变成一张表，再谈模型。
3. **T+8–24 h**：五问的"最小可交付"各跑通一遍（哪怕模型粗糙），确保每一问都有数、有图。
4. **T+24–40 h**：方法升级与对照实验。任何"我们比 X 好"必须有一个可复现的对照（本次：十种策略、同一折）。
5. **T+40–56 h**：写作。顺序：图表 → 结果段 → 方法段 → 摘要。摘要最后写。
6. **T+56–64 h**：评审前置。自己先按细则打分，再让 3–4 个独立 agent 盲评（本次四评委：建模/证据/写作/红队），按"性价比"修，不按"谁说得凶"修。
7. **T+64–72 h**：定页、查引用、查占位符、查匿名、导出单 PDF，留 2 h 缓冲。

## 六、下次要提前准备的东西

1. 一份**参数三分法表模板**（假设/估计/标定 + 来源 + 是否扫描），开赛就填，避免评委问"这个 1.5 哪来的"。
2. 一份**口径冲突清单**模板：同一现象在两问里用不同口径时，必须在正文显式写"两种口径不可互换"（本次 Q1 峰值窗口 1.4e8 m³ vs Q5 72 h 事件预算 3.5e8 m³）。
3. 一份**数字回填脚本**：正文表格由 JSON 自动生成，杜绝手抄。
4. 英文写作的句式库（摘要四段式、结果段"数字—机制—含义"三拍），避免现场憋句子。

# 长度微调（缩写 / 扩写）

这不是改写工具，是**卡页数**的工具。一次只动 5–15 个词；动完信息量必须一模一样。

## 缩写

```markdown
# Role
你是专注简洁性的学术编辑，特长是在不损失信息量的前提下压缩文本。

# Task
把【英文 LaTeX 片段】微幅缩减。

# Constraints
1. 幅度：减少 5–15 个词。不许大删大改，全部核心信息、技术细节、实验参数必须保留。
2. 手段：从句→短语；被动→主动（当更短时）；删填充词（in order to → to，due to the fact that → because）。
3. 风格：保持 LaTeX 纯净，不加粗不斜体不用破折号，不用 item 列表。
4. 事实：不许删限定条件（"under the same budget" 这类删掉就变结论强度）。

# Output
Part 1 [LaTeX]：缩减后正文，% _ & 转义，$...$ 原样。
Part 2 [中文回读]：逐句直译，核对信息是否完整。
Part 3 [修改日志]：中文，逐条列出删了哪个词、合并了哪个从句。

# Self-check
- 有没有不小心删掉实验参数或限定条件？→ 放回去。
- 是不是缩过头，把一段缩成一句？
```

## 扩写

```markdown
# Role
你是专注逻辑流畅度的学术编辑，特长是显化隐含逻辑。

# Task
把【英文 LaTeX 片段】微幅扩写。

# Constraints
1. 幅度：增加 5–15 个词。
2. 手段：显化原文隐含的前提、结论或因果关系（不能新增事实）；补必要的句间连接；把笼统描述换成更精确的表述。
3. 禁止注水：不加无意义形容词，不复述同一件事。
4. 风格同上：LaTeX 纯净，成段，不用列表。

# Output
Part 1 [LaTeX] / Part 2 [中文回读] / Part 3 [修改日志]（说明补的是哪条隐含逻辑）

# Self-check
- 新增内容是否是原文可推出来的？有没有幻觉或编造数据？
- 扩写后是否仍然凝练？
```

## 缩写清单（按性价比排）

1. `in order to` → `to`
2. `due to the fact that` → `because`
3. `it is worth noting that` → 删整句开头
4. `in the case of` → `for`
5. `has the ability to` → `can`
6. `a number of` → `several` / 直接给数
7. `make use of` → `use`
8. `in terms of` → 视语境重写（多数时候是废话）

## 扩写清单（只补三类）

1. 隐含前提：结论成立依赖的条件没写出来 → 补一句条件。
2. 隐含因果：A 导致 B 但只写了并列 → 补 `therefore` / `as a result` 或改成因果句。
3. 隐含对照：只写了「我们更好」，没写「比谁、在什么设定下」→ 补比较对象。

## 验收

- [ ] 词数变化在 5–15 区间（自己数）
- [ ] 参数、限定条件、比较对象一个不少
- [ ] 扩写部分没有新数字/新引用/新实验

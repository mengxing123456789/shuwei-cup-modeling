# 成稿加工（润色 / 长度 / 逻辑 / 去 AI 味）

## 先定操作

| 用户说的是 | 操作 | 默认强度 | 取模板 |
|---|---|---|---|
| 润色、改得更学术、语法对不对、母语者会这么写吗 | 润色 | 只在确有错误或口语化时改 | `references/polish-zh.md`（中文稿）/ `references/polish-en.md`（英文稿） |
| 太长了、压到 X 页、删掉十个词 | 缩写 | 只动 5–15 个词，信息一条不减 | `references/length-ops.md` |
| 太短、说不透、补一句 | 扩写 | 只显化原文隐含的内容，不加新事实 | `references/length-ops.md` |
| 逻辑检查、终稿校对、投稿前过一遍 | 红线审查 | 只报致命错，可改可不改一律不报 | `references/logic-check.md` |
| 像 AI 写的、去 AI 味、更像人写 | 去 AI 味 | 宁缺毋滥，原文够好就放行 | `references/deai.md` |

**载体判定**：输入含 `\cite{}`、`\section{}`、`$...$` 判 LaTeX；否则判 Word。载体决定转义方向（LaTeX 要转义 `% _ & #`，Word 不要）与标点（英文半角 / 中文全角）。

**强度只有一个默认值：最小干预。** 只有用户明确说「重写」「重写一遍」「换个写法」才切到重写模式；没说的话，改得越少越好。

## 输出契约（三个板块，不得增删）

- **Part 1 [成品]**：可直接粘贴的结果。判定为无需改动时，这里必须逐字等于原文。
- **Part 2 [依据]**：逐条说明改动对应的原句片段（引一行原文 + 一句为什么改）。
- **Part 3 [结论]**：`[已改] N 处` 或 `[检测通过] 原文达标，未改动`。
- 只输出这三块。不寒暄、不解释规则、不写「希望对你有帮助」。

## 四条不许

1. 不许为了显得干了活而改：换同义词、调语序、把「旨在」改成「拟」都算。
2. 不许把可改可不改写进问题清单，用词表硬凑存在感。
3. 不许在润色时夹带结构改动：改论点、加论证、删限定条件、动数字。
4. 不许改动 `\cite{}`、`\ref{}`、`\label{}` 的键与公式内容。

## 验收（任一项不过就重做）

- [ ] 判为「检测通过」时，Part 1 与原文逐字一致（用 diff 心态检查，不是「差不多」）
- [ ] Part 2 的每一条都能指到原文的哪一句
- [ ] 缩写后信息量未减：参数、条件、限定词一个不少
- [ ] 扩写没引入原文没有的事实、因果或数字
- [ ] 载体格式未破：LaTeX 无裸 `%`，Word 无 Markdown 标记

# 思路模板（THINKING CANVAS）

一份可填空的解题路线图。填空项写成 `【…】`，填不完就不要开始写正文——
空白处就是评委扣分的地方。时间按 96 小时赛制（亚太杯四天）给，国赛三天按 ×0.75 折算。

每一节末尾有一行 **门（gate）**：过不了门，不许进下一节。门是防止"写到第三问才发现第一问口径错了"
的唯一手段，本项目为此返工过三次。

---

## 第 0 节　读题（0–1.5 h，不许打开任何工具）

抄，不解读。只抄三类句子：

| 类别 | 抄什么 | 用途 |
|---|---|---|
| 要求句 | 含 "you are required to" / "determine" / "propose" / "分析…提出…" 的整句 | 每个子问对应一条；后面所有小节标题从这里长出来 |
| 约束句 | 单位、时间范围、地区范围、给定量 | 变成 assumptions 或 notation |
| 交付句 | "give the result of" / "a table of" / "a letter to" | 决定该问的产出形态（数/表/方案/信） |

**必修**：把每问的"要求句"编号 Q1a、Q1b、Q2…，写在一张纸上贴在屏幕边。全文每完成一小节，回来勾一个。

**门 0**：`out/00-problem.md` 里每个 Qx 都有且仅有一条题目原文句子作依据。有一条对不上就回去读题，不要开始建模。

---

## 第 1 节　认题型（1.5–2 h）

16 篇一等奖的骨架按题型分族，**选错族 = 结构分全丢**。按题面特征判定：

| 判定信号（题面出现这些词） | 题型 | 骨架族 | 该族必有的章 |
|---|---|---|---|
| 图像、几何、测量、识别、仿真物理场 | A | A-α | 预处理章（每问内 X.1） |
| 装置、传热/传质、受力、调度、容量 | B | B-α | 机理论证 + 问内检验（**不许"仿真即验证"**） |
| 数据表、指标、时间序列、政策情景、评价 | C | C-α | **数据章前置** + 单列敏感性 |
| 组合、指派、装箱、整数、量子/QUBO、博弈 | D | D-α | 一模型一章 + 规模阶梯 |
| 聚类、时序（纯） | E | E-α | 时序四步（平稳→白噪→估计→验证） |

**实测依据**：独立评价章 **16/16**、检验章或问内检验块 **14/16**、题面分析章 **14/16**
（复算脚本见 `scripts/gauntlet_check.py` 同目录的 `_audit`）。三章是"必有三章"，
不是"最好有三章"——唯一缺检验的两篇（`2205838`、`2307379`）正文里都出现了
"the results are accurate" 这类无量化自夸，是本 skill 明令禁止的写法。

**门 1**：`out/01-type.md` 写下题型、骨架族、五个必须出现的章名、以及"我从同类一等奖里抄了哪一节的结构"（写队号）。

## 第 2 节　给数据定位（2–3 h）

附件数据是**唯一的免费午餐**，也是评委会重点看的"你是不是真的用了它"。

1. 每个附件：行数、列数、时间跨度、缺失率、单位。**先报数再谈方法**。
2. 有没有需要外部数据的子问？若有，先按 `RULES.md` R-M01/R-M02 建 ledger，抓得到就抓，抓不到就写"未验证"
   并把该问改成"给定数据下的上界估计"。
3. 数据的三个陷阱，看见就必须写进 assumption：
   - 口径变更（某年统计口径换了）→ 结构断点；做 DID 或分段回归。
   - 单位混用（万吨/吨、当月/累计）→ 单独一节写换算。
   - 缺行 ≠ 缺值：Comtrade 对"无交易"是省略该行，不是给 0（本项目差点把出口写成 0）。

**门 2**：`data/ledger.json` 里每条数据的 `sha256` 与 `fetched_at` 齐全；附件数据的行列数写进正文数据节第一句。

---

## 第 3 节　符号表与假设（3–4 h）

**顺序不能反**：先符号表，后假设。反过来会写出"假设里出现两个 M"的事故（本项目 −0.6047 M 就是这么来的）。

符号表三列：符号 / 含义 / 单位。规则：

- 一个符号只许一个含义。上下标区分向量与标量，不许靠上下文猜。
- 出现在正文的每个参数必须在此表里；表里每个符号必须在正文出现 ≥1 次。
- 希腊字母用完了就换大写拉丁字母，不要造新符号。

假设分两类，**分开放**：

| 类型 | 长什么样 | 要求 |
|---|---|---|
| 结构性假设 | "市场按 Armington 结构分割" | 要能说出"换成别的方式会怎样" |
| 可检验假设 | "关税弹性在 [2,8] 内" | 必须给检验方法与结果（第 7 节） |

**禁写**：`Assuming the data is credible`、`a certain degree of`、`can not do exactly`。
这三句是一等奖论文里被评审判为"免检式假设"的原句（`2303763`、`2213503`）。

**门 3**：用脚本自查符号一致性——把符号表里的符号逐个 `grep` 正文，出现 0 次的删掉，正文里有但表里没有的补上。

## 第 4 节　先写"什么结果会让你改主意"（4–4.5 h）

这是本项目唯一救回符号的一步。在跑模型**之前**写下来：

```
我预期 Q2 的结论是：【符号 + 量级 + 排序】
如果实际得到【具体数值条件】，我会认为：
  (a) 我的口径错了 → 检查【分母/基准年/名义实际】
  (b) 我的模型错了 → 检查【约束是否 binding / 解是否在网格边】
  (c) 结论真的是反的 → 那我必须在正文写清"与直觉相反，因为…"
```

实测价值：本项目 Q2 零关税情景算得 −1.06 bn（往往直觉是"降关税 → 消费者受益 → 福利上升"）。
因为事先写了这条，才发现是**基数错配**（用变动后的量算变动前的成本），改成 Laspeyres 后得 −0.32 bn。
没有这一步，就会把它当成"结论反转"写进正文，然后被评审一眼看穿。

**门 4**：`out/04-expectations.md` 存在，且每个子问至少一条"会让我改主意"的条件。

---

## 第 5 节　建模与求解（4.5–20 h）

按骨架族走。共通要求：

1. **每问一章**，章内四段：`X.1` 预处理/数据 → `X.2` 模型 → `X.3` 求解结果 → `X.4` 检验。
   C 组把数据提到第 4 章单列，问内从 `X.1 Data insight` 起。
2. 模型里每个参数都要问一遍"它到底影响什么"——**惰性检验**。完全不影响结论的参数，要么删，
   要么写成"在【条件】下才起作用"的正面结论（这往往就是创新点）。
3. 解出来先查三件事再报：是否 binding、是否在网格边、点估计是否落在自己的区间外。
   三件事任一为真，正文必须显式说明，不许当成正常解。
4. 报数必须带口径：分母是什么、基准年、名义还是实际、是否年化。两条口径不同的数不许并排放进一句。

**门 5**：`data/results_*.json` 存在；每个"最优"有邻域性质；每个参数有惰性结论。

---

## 第 6 节　敏感性、稳定性、误差（20–26 h）

三种强度，**都必须报**，且必须报不利的那一半：

| 强度 | 做法 | 报什么 |
|---|---|---|
| 扰动 | 参数 ±10% | 结论是否翻转；排序位移几位 |
| 重抽 | 数据 bootstrap 500 次以上 | top-1 的存活率（本项目 63.6%–67.0%，必须写出来） |
| 分解 | Sobol / 方差分解 | 各参数贡献占比；先算临界面，防"取样盒错位造成的伪零" |

**写作陷阱**：只报"排序位移 0"会让读者以为完全稳健。实际 top-1 只活 65%。
正确写法是两句话都给："秩相关在 ±10% 扰动下位移 0，但重抽后首位年份只以 65% 的概率保持不变。"

**门 6**：三种强度至少两种有数字；不利的一半写出来了。

---

## 第 7 节　优缺点（26–28 h）

独立成章 **16/16** 篇都有，标题随便（Advantages / Strengths and Weaknesses / Model Limitations）。

写法：**缺点必须是可检验的边界，不是自我安慰**。

- ✗ `There is a certain amount of error.`（`2205838` 原句，零信息）
- ✓ `替代弹性被固定在 5.5，敏感性表显示取 4.0 时福利增量降到 0.31 bn；我们没有识别它的数据，这限制了政策结论的量级。`

优缺点各 3 条，强项要能引出"所以本文的结论可以用于…"，弱项要能引出"所以本文不主张…"。

**门 7**：每条缺点都能指到正文某个数字。

---

## 第 8 节　创新点声明（28–30 h，可与第 5 节并行）

只允许四类（16 篇一等奖里真具备创新点的只有 7 篇，全是这四类）：

| 类型 | 一句话形式 | 一等奖实例 |
|---|---|---|
| 换表征 | 把 A 从【旧表示】改成【新表示】，于是【原来做不到的】变得可行 | `2309364` 用图像亮度反推物距；`24207218` 把三种模型统一改写成 QUBO |
| 换约束表达 | 把【约束】写成【更紧的等价形式】，规模降 N% | `25310840` K-means 时段聚类，48% 降维、520 bit、9.1 s、与经典 MILP 差 <2.5% |
| 换规模 | 从【小规模】做到【大规模】，代价是【…】 | `25310840` 规模阶梯 |
| 跨学科映射 | 借【学科】的【定律/曲线】解释本题 | `2201058` Murray 定律做翅片分形；`25301412` Laffer + Stackelberg |

**警示**：`25302425` 三问降幅都是 33.3%、时标因子恒 1.500 ——"多关节协同优化"在数值上等价于
"整体降速 1/1.5"。**如果创新点能被一个标量解释掉，它就不是创新点。** 自查：把创新点写成一个数字，
若这个数字能复现全部三问的结论，判为无效。

**门 8**：`out/08-innovation.md` 里那句话能被一个数字检验；且这个数字不能解释其余全部结论。

## 第 9 节　摘要（30–34 h，最后写，最先被读）

四段，顺序固定，段首 `\textbf{}`：

```
\textbf{Background and Task}     现象一句 + 任务清单 + 本问共 N 个模型
\textbf{Modeling Framework}      每问一个具名模型，模型间用 based on / building on / extending 串起来
\textbf{Results per Question}    逐问一句，每句至少一个数字
\textbf{Validation and Limitation} ≥2 种验证手段 + 1 条具体局限
```

数字配额：**不同的数 ≤8 个，密度 ≤2 个/100 词**。16 篇一等奖中位数是 2.5 个 / 0.73；
本项目曾写到 44 个 / 11.25（p100，17 倍中位数），是反模式 P1 的"纯数据堆砌"。

**门 9**：跑摘要检查器 v；四段齐全、顺序正确、数字在配额内、关键词与第 2 段模型名同序。

## 反模式清单（一眼判死）

| 编号 | 症状 | 判据 |
|---|---|---|
| P1 | 摘要只有方法清单 / 只有数字堆砌 / 结尾无数字 | numbers < 3 或 density > 2 |
| P2 | 没有检验章也写"结果准确" | test_sec = 0 且正文出现 accurate/reliable/reasonable |
| P3 | 假设不可检验 | 出现 "certain degree"、"Assuming the data is credible" |
| P4 | 缺点空转 | 缺点里找不到任何数字 |
| P5 | 图号/章号错、拼写错（Wrok、Evalustion） | 编译后查交叉引用未定义 |
| P6 | 符号表单位重复（"Square meters (square meters)"）、用 `•` 导致无法 `\ref` | 假设/符号表逐条编号 |
| P7 | 某小问被"文章化"（公开信、报告）后不引用前问数字 | 该章内 `[表/图/式]` 引用数 = 0 |

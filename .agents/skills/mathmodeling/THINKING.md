# 解题思路模板（THINKING.md）

拿到赛题后的前 90 分钟决定成败。这份模板按**分钟**排，每一步都有产出物和"过了什么才能进下一步"。

---

## 0–15 分钟：读题，不动手

**只做一件事**：把题目原文里每一个"要求你"的句子抄下来，编号 Q1、Q2…

产出：`out/00-problem.md` 的开头一节：

```
Q1 原文："…" → 要的交付物形态：一个百分比 / 一个方案 / 一个排序
Q2 原文："…" → …
```

**过关条件**：每个 Q 都能对上原文的一句话。对不上的是你自己加的题，删掉。

**这 15 分钟里禁止做**：查文献、看往年论文、想方法。先读题。

## 15–30 分钟：查附件数据

```
行数 × 列数 × 缺失率 × 单位 × 时间跨度
```

本项目在这里发现过一个决定性事实：附件里中国目的地的月度出口**在 5 月之后整行消失**，而全球合计
每个月都在。**"没有记录"与"记录为零"是两件事**，这一条直接改变了 2025 年情景该用哪个模型。

产出：数据事实清单，每条带"这个事实会改变什么"。

**过关条件**：每个附件表都报出 行数/缺失率。没报的不许进建模。

## 30–50 分钟：选题型，找同类一等奖论文

题型决定方法，不是反过来。

| 题型 | 识别特征 | 方法簇 |
|---|---|---|
| A | 给图片/几何/信号 | 分割、检测、重建、配准 |
| B | 给物理过程/工程约束 | 机理建模、微分方程、多目标优化、元启发 |
| C | 给统计数据 + 政策/经营问题 | 口径定义、识别、估计、反事实、稳健性 |
| D | 给组合结构（调度、装箱、路由） | 整数规划、QUBO、图论、贪心+局部搜索 |

然后**只读同类题的一等奖论文**（C 题就读 C 题），读三样：摘要怎么组织、有哪些图、稳定性怎么写。
不要读跨题型的 —— 方法不通，结构也不通。

## 50–70 分钟：写符号表与假设

见 `modeling.md` 第 1–2 节。**先写符号表再看任何文献。**

符号表定下来后，问三个问题：

1. 有没有一个符号对应两个量？（本项目踩过：`M` 同时是"六来源合计"和"全球进口"）
2. 每个假设是结构性的还是可检验的？可检验的有没有检验方法？
3. 模型里有哪些参数？它们会真的进入结果吗？

## 70–85 分钟：画出"结论长什么样"

在动手算之前，先写下你预期会得到的结论，以及**什么结果会让你改主意**。

```
预期：关税上升 → 进口下降 → 国内生产上升 → 福利方向不确定
会改主意的情况：福利在零关税点不为零（说明基准口径错了）
```

这一条在本项目救过一次命：零关税时算出 −1.06 bn 福利，立刻暴露了两个进口基数混用。

## 85–90 分钟：决定这一次的"创新点候选"

不是先做完再找创新 —— 那样找到的都是包装。

从三个方向里挑一个，写进 `out/plan.md`：

| 方向 | 形态 | 本项目实例 |
|---|---|---|
| 换表示 | 把 A 从"逐点求解"换成"学一个映射"，于是原本做不起的全局分析变得做得起 | 代理模型 → Sobol 分解 |
| 换问题 | 把"求一个点估计"换成"求一个决策规则"，于是识别不足不再是缺陷 | 弱识别 → 关税区间 + 最小最大后悔 |
| 换失败为结论 | 证明某模块在什么条件下完全不起作用，并给出临界条件 | 容量惰性 + 临界面 m\*(τ,σ) |

**判据**：一句话能说出来，形式是"把 A 换成 B，于是 C 变得可行/不可行"。说不出来的不是创新点，是工作量。

---

## 90 分钟之后：按问推进

每个子问走同一条流水线：

```
口径定义 → 模型 → 求解 → 对账 → 图 → 一句结论
```

**每问必须有的三样**：
1. 口径定义句（分母、基准年、名义/实际）；
2. 至少一个"如果口径换一种会怎样"的数字；
3. 一句"本问结论"，不用形容词，只用方向 + 量级。

## 时间预算（四天赛）

| 阶段 | 时长 | 不可压缩的部分 |
|---|---|---|
| 读题 + 数据 + 定框架 | 3 h | 是 |
| 逐问求解 | 18 h | 是 |
| 训练/大规模计算（若有） | 4 h（可后台） | 否 |
| 对账 + 图 | 6 h | 是 |
| 写正文 | 14 h | 否（可压缩） |
| 合规 + 压页 | 5 h | 是，且**先做** |

> **最后 12 小时只改会废稿的项**：正文页数、中文字符、机构名、队号占位符、参考文献格式。
> 绝不在最后 12 小时改模型。

## 反模式清单

| 反模式 | 症状 | 后果 |
|---|---|---|
| 先找方法再找问题 | "我想用遗传算法" | 评委看得出问题被削足适履 |
| 摘要当账本 | 摘要里 40 个数 | p100，偏离评审习惯 17 倍 |
| 敏感性分析没有数字 | "我们做了敏感性分析" | 零分句 |
| 边界解当内点 | 最优 tariff 恰在网格边 | 被抓 |
| 点估计与区间并排 | 411.9 vs [27.9, 353.6] | 读成矛盾 |
| 报零不查盒 | "这个参数不重要" | 取样盒放错位置造成的伪零 |
| 只报有利的一半 | 只报"排序不变"不报"top-1 只活 65%" | 挑结果的痕迹 |
| 集成当创新 | "我们综合运用了多种方法" | 官方淘汰过大量这类 |

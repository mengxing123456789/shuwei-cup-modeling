# 论文撰写（writing.md）

依据：APMCM 官方规则（评分七条）+ 16 篇**已核验队号**的一等奖论文实测分布。
规则编号见 `RULES.md` 的 `R-W` / `R-V` 组。

## 0. 先看评审计分点

官方七条评分准则（2026 版规则 四）：

1. 对题意的满意解释，含糊概念要解释清楚
2. 明确的假设，并说明理由
3. 从问题分析出发的建模理由
4. 能有效解决问题的模型
5. **模型的稳定性检验**
6. 优缺点讨论与明确结论
7. **完整准确的摘要**

第 5 和第 7 条是大多数队伍失分的地方，也是本 skill 花最多篇幅的地方。

## 1. 摘要：唯一被反复读的东西

官方原文：*"摘要占据了相当大的比重，以至于有的时候获奖论文之所以能在众多论文中脱颖而出是因为
其高质量的摘要"*；*"简单重复比赛题目和复制粘贴引言中的样板文件的摘要一般将被认为是没有竞争力的"*。

### 四段式，顺序固定

```latex
\begin{abstract}
\textbf{Task.}  题目要你解决什么，用你自己的话，一句话到三句。
\textbf{Model.} 你建了什么，模型的**名字**必须出现（一等奖 16/16 都命名了模型）。
\textbf{Results.} 最关键的三到五个数，每个都带口径。
\textbf{Validation.} 你怎么知道自己没算错。
\end{abstract}
```

16 篇一等奖实测：模型命名 16/16、具体结果 15/16、验证 15/16、逐问组织 13/16、背景铺垫 9/16。
**背景铺垫是加分项不是必需项；命名模型是必需项。**

### 数字配额

| 指标 | 一等奖中位 | p75 | 硬上限 |
|---|---|---|---|
| 摘要词数 | 374.5 | 431 | 落在 IQR 内 |
| 不同数值个数 | **2.5** | 8 | **≤8** |
| 数值密度（每 100 词） | **0.73** | 2.49 | **≤2** |

本项目曾写到 **44 个数值、11.25/100 词**（p100，17 倍中位数）。那不是"更充分"，是偏离评审习惯：
评委读摘要找的是**结论**，不是账本。改到 5 个 / 0.99 后落到 p62 / p56。

**怎么砍**：留"方向 + 量级 + 一个关键数"。三个子问只报三个数，其余移到正文。

## 2. 正文骨架（按题型选）

| 题型 | 典型内容 | 骨架 |
|---|---|---|
| A 图像/几何/工程 | 分割、检测、重建 | 数据与预处理 → 方法（含损失/评价指标）→ 结果（含对比基线）→ 稳定性 |
| B 物理/工程优化 | 多目标、微分方程、元启发 | 机理模型 → 离散化 → 优化 → 帕累托与权衡 |
| C 数据/统计/经济 | 回归、预测、政策评估 | 口径定义 → 识别策略 → 估计 → 反事实 → 稳健性 |
| D 前沿/交叉 | QUBO、MILP、图论 | 问题变换 → 求解器 → 规模与精度 → 可行性 |

**每问一个小节，小节末尾一句话给结论。** 没有"本问结论"的小节，评委会认为你没回答问题。

## 3. 每个数字带口径

一句话里出现数字，就要能回答：分母是什么？基准年？名义还是实际？年化了吗？

本项目踩过的：Q4 报"累计 411.9"，而蒙特卡洛均值是 183.0、区间 [27.9, 353.6]。两个数并排出现，
读者会以为点估计在自己区间之外。**分成两句**：

> 若有效税率真的停在 6.6%，累计收入约 \$412 bn；若税率随我们测到的弹性不确定性每年重抽，
> 中心预期接近 \$183 bn。

## 4. 稳定性检验怎么写才不虚

"我们做了敏感性分析"是零分句。要写成：

> 权重扰动 ±10%，两个年份之间的排序位移为 **0**（排序由趋势驱动，与权重无关）；
> 数据扰动 ±10%（500 次重抽），top-1 年份只在 **63.6%–67.0%** 的重抽中保持第一。

**要敢报不利的一半**：上例的后半句才是真正的检验。只报前半句，评委看得出你在挑结果。

## 5. 优缺点：写"边界"，不写"不足"

一等奖 14/16 有局限性小节，但**没有一篇写过自我否证**。所以"承认局限"是基本要求，"报出被自己推翻
的结论"是稀缺动作。

写法：
- 强项写**机制**（为什么这个方法在这个问题上比别的强），不写"我们的模型很完善"；
- 弱项写**边界条件**（什么情况下失效、失效后偏差方向），不写"由于时间有限"。

## 6. 参考文献

- 每条带类型标记：`[J]` 期刊、`[M]` 专著、`[R]` 报告、`[DB/OL]` 数据库、`[EB/OL]` 网页。
- 期刊给卷(期)与页码；专著给出版地与出版社；URL 给 `accessed YYYY-MM-DD`。
- **正文 ≥70% 被 `\cite` 过**。本项目曾被评审判 FAIL：18 条参考文献只被引 2 条。
- 出版社名里带机构名的要换（`Oxford University Press` → `Oxford: Clarendon Press`），
  因为全文不许出现机构名。

## 8. 页数：唯一可靠的压页手段

正文超过 30 页时，以下手段**实测都无效或几乎无效**：

- 把 `[H]` 浮动体改成 `[htbp]`（36→35 页）；
- 把相邻图合并成 minipage 双栏（79→80 页，浮动体只是挪了空白）；
- 把数字堆改成叙述（替换文本比删掉的数更长，36 页不变）；
- 收紧结论尾句、折叠分隔符、压缩"模型评价"小节（各 0–1 行效果，反复回弹）。

**有效的手段只有一条：把归档表搬进未编号的附录。** 本项目实测：

```
tab_surro + tab_audit + tab_sobol + tab_binding   → 32 页
+ tab_sigmarob + tab_lp                            → 31 页
+ tab_reshore                                      → 30 页
```

正文保留全部论断，改成"见附录 C 表 X"。附录无页数上限。

**判断溢出在哪一页**：`pdftotext` 分页后看正文最后一页的**非空行数**。若最后一页只有参考文献的尾巴，
那就是参考文献跨页，不是正文超了 —— 这时该动的是参考文献起点，不是删正文。

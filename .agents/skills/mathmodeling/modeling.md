# 建模与求解（modeling.md）

规则编号见 `RULES.md` 的 `R-M` 组。这里讲**怎么做到**。

## 1. 把题目变成符号表，再谈方法

先写符号表，再写模型。符号表三列：符号 / 含义 / 单位。**一个符号只许一个含义**。

本项目曾出现 `M` 同时表示"六个来源的进口量合计"和"全球进口量"：`q2_autos.py` 里
`M = sum(q.values()) = 7.0816 M`，而 `par["import_share"] * sales_m = 7.6863 M`，两处都叫 `M`。
后果是每次求 domestic 变化都被注入一个恒定的 **−0.6047 M**，在零关税（政策完全没变）时算出
福利 **−1.06 bn 而不是 0**。这类错误不会报错，只会让结论悄悄偏。

写符号表时对每个符号问一句：**它有没有第二个名字？** 有，就拆成两个符号。

## 2. 假设分两类，分开放

| 类型 | 特征 | 怎么写 |
|---|---|---|
| 结构性 | 模型只有这样才能存在（完全竞争、CES 偏好、无调整成本） | 写出它替代了什么，违反后模型要换成什么 |
| 可检验 | 可以被数据否掉（弹性取值、替代弹性区间、转移份额） | 给检验方法与结果，失败要报出来 |

本项目把弹性写成一个"已校准"的数，而代码里是硬编码的 `sigma = 6.5`，**没有任何程序在 σ 上做
最小化** —— 这就是把可检验假设当结构性假设写。读者一查附录就露馅。

## 3. 参数进入结果吗（惰性检验）

**每个参数都要过一遍 ±10% 扰动**，看结论动没动。完全不动的是惰性参数，有三种命运：

1. 删掉（它没用）；
2. 保留并证明"它只在某条件下起作用"—— 这个条件本身往往是**创新点**；
3. 保留并明确写成"结构性惰性"，说明为什么不该动。

本项目 `diversion` 在 σ=6.5、τ=47% 下取 0.2 / 0.5 / 0.9，美国进口量是**一字不差**的
15.788930 MMT —— 因为它只加到容量上限上，而上限根本没绑住。这被写成正面结果：*容量模块在本情景
完全惰性，真正的约束是价格*。

### 伪零：报"零"之前必须先算临界面

Sobol 报"容量参数 ST = 0.0000"，看起来就是惰性。但**取样盒的位置**会让这个零变成假象：

```
临界倍数 m*（巴西容量乘数，低于此值上限生效）在 τ=0.47 时是 0.818
而 Sobol 取样下界是 0.85 → 盒子里根本没有会 binding 的点 → ST 必然为 0
```

修法有两条，都做：
1. 算一张 `m*(τ, σ)` 面，画成"阈值一条线 + 量一族曲线"，说明盒子在 τ>0.7 才跨过临界线；
2. 在盒子里随机抽 4,000 点，数真正 binding 的次数（本项目 **7 次，全部巴西**，0.175%），
   再报巴西在盒下界处用到帽值的 **88.5%–99.5%** —— "紧但没绑住"是比"不重要"准确得多的说法。

## 4. 离散开关与连续参数分开

有制度性开关（禁运、配额触发、halt）时，**开关对结论的影响通常远大于任何连续参数**。

本项目：把 halt 当成第十个二值输入，1,200 抽样 × 2 制度 = 2,400 次精确求解：

| 输入 | 对美国进口量方差贡献 |
|---|---|
| halt 开关 | **94.60%** |
| 关税 τ₁ | 2.43% |
| σ | 0.01% |

而"连续框内"，关税解释 96.4%、σ 只解释 3.1%。**两张表必须并排出现**，否则读者会以为"关税是主因"。
正确的一句话是：*是离散规则决定答案，弹性只是给它定价。*

## 5. 口径陷阱清单（每条都翻过符号或差过倍）

### 5.1 Laspeyres vs Paasche：会翻符号

消费者成本 = 价格指数变动 × 基准消费量。若用**税后**数量做权重（Paasche），等于让被政策引致的
替代自己把成本压回去：

| 关税 | Paasche ΔW | Laspeyres ΔW | 倍数 |
|---|---|---|---|
| 15% | +1.12 bn | **−0.32 bn** | 1.54× |
| 47% | +2.08 bn | **−6.77 bn** | 2.53× |

符号翻转。**成本一律用基准量加权**，并在正文写明"这是 Laspeyres 型指数"。

### 5.2 指数 vs 加总

CES 的品种数量指数在替代发生时**不动**（本项目恒为 105.0327 MMT），而"各来源吨数之和"会涨
（105.03 → 105.94 → 112.59）。把加总上涨写成"需求增加"是错的 —— 那是**向供给曲线更平的来源替代**。

### 5.3 上限容忍度

`solver` 的 `binding = qty > cap − 1e-3`。巴西 100.98 / 101.06 = **99.92%** 时返回 False。
正文若写"未触及上限"就被抓。正确写法：给每个来源的 `qty/cap` 百分比，再定性。

### 5.4 求和 vs 乘以

本项目曾把"分段进口额 30.25 + 9.75 + 23.32"与"总额 40.39"并排放，读者以为 63.32 是错的。
查税号后才知道 **HS 8541（分立器件）与 HS 8542（集成电路）是不相交的两个税号**，残差
`8541 − 四个子目 = −16.683` 为负，证明不是父子关系。所以 63.32 是对的，错的是**叙述**。

教训：当一个"合计"和它的分项对不上时，先查**分类学**（税号、口径、科目），再改数字。

### 5.5 点估计 vs 区间

确定性累计 411.9 落在蒙特卡洛 90% 区间 [27.9, 353.6] **之外**。这不是矛盾，是两个问题：
前者假设税率固定 6.616%，后者每年重抽税率。**必须分成两句写**，并明确哪个是"若税率不变"。

## 6. 网格边界解

优化跑在网格上时，最优解落在网格边就**不能当内点报**。

本项目 Q3 中低端最优关税都在 0.25 边界。放宽到 0.40 后：1.14 → **1.2374**、2.41 → **2.6777**。
正确做法是表格里给边界解打星，正文给放宽后的值，并说明"真实最优在网格之外"。

## 7. 敏感性分析的三种强度

| 强度 | 做法 | 能证明什么 |
|---|---|---|
| 扰动 | ±10% 权重/参数，看排序变不变 | 结论对小幅误差稳 |
| 重复抽样 | 500–5,000 次，看 top-1 命中率 | 结论对分布假设稳（本项目 top-1 存活仅 63.6–67.0%） |
| 全局分解 | Sobol S1/ST | 每个输入贡献多少方差 |

扰动说"排序不变"很可能是因为**数据趋势驱动排序**，与权重无关 —— 那要明说，别当成功。

## 8. 求解器的已知坑

```
solve_equilibrium(p0, q0, shares, cap, sigma, eta, tau0, tau1, pass_through,
                  Q0, eps_d, demand_growth, diversion, halt_us=False)
```

- **σ 是第 5 个位置参数**。把 τ₁ 传到第 5 位会报
  `TypeError: solve_equilibrium() got multiple values for argument 'sigma'`。一律用关键字。
- 返回 `total_mmt` 是 `sum(qty)`，**不是** CES 指数；CES 指数恒等于 `Q0`。
- `baseline_2024` 返回的份额键是 **`s0`**（不是 `shares`）。
- `halt_us=True` 是把美国容量设成 1e-6，不是把需求设成 0 —— 所以"halt 让美国归零"是**构造出来的**，
  正文要这么写。

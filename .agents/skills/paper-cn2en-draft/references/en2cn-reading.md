# 英转中 · 速读翻译

用途是**快速读懂**，因此牺牲文采，保证「能对着原文一句句回查」。

## 可直接粘贴的模板

```markdown
# Role
你是计算机领域的学术翻译官，任务是帮研究者快速理解英文论文段落。

# Task
把【英文 LaTeX 片段】翻译成流畅易读的中文文本。

# Constraints
1. 语法清洗：
   - 删除所有 \cite{} \ref{} \label{} 等索引命令，不保留也不翻译。
   - \textbf{text}、\emph{text} 这类修饰命令只翻译大括号内的 text，丢掉格式本身。
   - 数学公式转成可读的自然语言或普通符号（$\alpha$ → alpha，\frac{a}{b} → a/b），不保留 LaTeX 语法。
2. 翻译原则：
   - 严格直译：不润色、不重写、不"顺手优化逻辑"。
   - 保持英文语序，便于逐句对回原文。
   - 原文有语法错误或表达生硬时如实反映，不要自动纠正。
3. 输出：只给翻译后的纯中文段落，不含任何 LaTeX 代码。

# Input
[在此处粘贴英文 LaTeX 代码]
```

## 与「中转英」的关键区别

这条路**故意不做润色**。译者一旦顺手改逻辑，回查就失效——你无法判断是原文含糊，还是译者替你补了。

## 实用场景

1. 读别人的论文，抓方法与实验设置（先读 Methods + Experiments，跳过 Related Work）。
2. 校对自己的英文稿：先英转中，再看中文是否读得通——读不通的地方，英文多半也写坏了。
3. 给组会讲论文前快速过一遍。

## 验收

- [ ] 中文里无 LaTeX 命令残留
- [ ] 数学符号以可读形式出现，不是 `\frac{}{}`
- [ ] 句序与原文一致，能逐句对回
- [ ] 没有出现原文没有的因果、限定或结论

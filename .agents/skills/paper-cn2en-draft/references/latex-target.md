# 中转英 · LaTeX 载体

成品要能直接粘回 `.tex`，所以格式纯净度与转义正确性优先于文采。

## 可直接粘贴的模板

```markdown
# Role
你是顶会（ICML / ICLR / NeurIPS / ACL）级的科研写作专家，同时是最挑剔的审稿人。你对逻辑漏洞与语言瑕疵零容忍。

# Task
把【中文草稿】译成可粘回 .tex 的英文学术段落。

# Constraints
1. 排版：正文不加粗、不斜体、不加引号；不用破折号（—），改用从句或同位语；不用 \item 或任何列表，必须成段。
2. 语言：逻辑严谨、用词常见、表达凝练；不堆砌辞藻；避开 AI 高频词（leverage / delve into / tapestry / pivotal / underscore 一类）。
3. 时态：描述方法、架构、结论用一般现在时；仅明确历史事件用过去时。
4. 转义：% _ & # 必须转义（\% \_ \& \#）；$...$ 内公式原样保留；\cite{} \ref{} \label{} 的键原样保留。
5. 事实：不新增原文没有的结论、数字、引用、实验条件；原文缺失处写 [TODO: 补 …]。

# Output
Part 1 [LaTeX]：只有英文 LaTeX 正文。
Part 2 [中文回读]：Part 1 的逐句直译，句数与 Part 1 一致。
Part 3 [改动日志]：中文，列出取舍（如「把并列三句合成一句」「原文第二句缺主语，按上下文补为 we」）。

# Self-check（后台做，不要打印过程）
- 有无残留中文？有无未转义的 % _ & #？
- \cite 的键是否有写错、漏掉、编造？
- Part 2 是否逐句对应、无自我发挥？

# Input
[在此处粘贴中文草稿]
```

## 易错点（按出现频率排）

1. **百分号**：`95%` 直接进 `.tex` 会把后面整行注释掉。这条被漏得最多。
2. **下划线**：`model_v1` 在数学模式外必须写 `model\_v1`。
3. **合并句子后公式跑位**：把两句合成一句时，`$...$` 的相对位置要保持可读，不要把公式挪到句尾变成装饰。
4. **术语被译**：`few-shot`、`ablation`、`SOTA` 保留英文，不要译成「少样本学习」「消融实验」这种在英文正文里出现的中式直译。
5. **主语归因漂移**：中文常省略主语，译成英文补 `we` 时要确认原文主语确实是作者团队，不是被引方法。

## 验收

- [ ] 粘进 `.tex` 能编译（至少不因转义报错）
- [ ] `\cite` 键与 bib 一致，无编造
- [ ] Part 2 逐句可对

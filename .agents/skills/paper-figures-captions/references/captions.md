# 图注与表注

## caption 的三段结构

一句顶用的 caption 只回答三个问题，按顺序：

1. **这是什么**：图/表展示的对象与范围（本文方法在 X 数据集上的 Y 结果）。
2. **关键设定**：读者无法从图里看出的条件（分辨率、预算、few-shot 设定、运行次数）。
3. **该看出什么**：一句话指向核心现象，不给结论强度。

## 图注模板

```markdown
# Role
你是学术论文的图表编辑，负责写符合目标期刊/会议规范的图注与表注。

# Task
为【图/表内容描述】写图注（或表注），中文与英文各一版。

# Constraints
1. 结构：先一句说明图展示什么（含数据集与方法范围），再补关键设定（条件、单位、样本量、误差表示），最后一句指向核心观察。
2. 英文不加粗、不用缩写形式、句首大写其余小写（除专名），结尾不加句号（若目标会议要求加则加）。
3. 中文全角标点，术语与正文一致。
4. 不在图注里放正文没定义的缩写；首次出现必须展开。
5. 不写"显著优于""大幅提升"这类结论词，除非用户明确要求。
6. 图内已标明的信息不重复叙述（如坐标轴已有单位，就不再写单位）。

# Input
[图/表内容描述 + 目标会议/期刊 + 是否含误差棒/显著性标记]

# Output
Part 1 [成品]：English caption + 中文 caption
Part 2 [依据]：为什么这样分段、关键设定为什么必须写
Part 3 [落地]：[可直接用] 或需替换的占位符
```

## 表注与其他差异

表注额外要交代三件事：

1. **加粗/下划线含义**：加粗=最优，下划线=次优（或反之，但必须写明）。
2. **符号含义**：`†` 是什么、`*` 表示什么显著性水平。
3. **判定口径**：最优是按哪个指标、哪个子集判的；是否跨数据集平均。

## 常见硬伤

| 硬伤 | 修法 |
|---|---|
| 「如图所示，我们的方法更好」 | 删掉「如图所示」，直接写设定，让图自己说话 |
| caption 里出现图里没有的缩写 | 展开或删掉 |
| 中英两版信息不等价（中文说了预算，英文没说） | 逐句对齐重写 |
| 表注没写加粗含义 | 必补，否则表格无法解读 |
| 图注重复坐标轴已有的单位 | 删 |
| 用「Figure 1 shows that ...」开头 | 多数会议接受，但 `Fig. 1` 更紧凑；按目标会议模板定 |

## 验收

- [ ] 中英两版信息等价
- [ ] 关键设定（条件/单位/样本量/误差）齐全
- [ ] 无未展开缩写
- [ ] 无结论强度词（除非要求）
- [ ] 表注写明了加粗与符号含义

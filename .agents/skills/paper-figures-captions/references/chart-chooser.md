# 实验图型选择

选图只问三句：**x 轴是不是连续量？比的是同一主体的不同方法，还是不同主体？要传达绝对值、趋势，还是分布？**

## 决策表

| 数据形态 | 用这个 | 不要用 | 原因 |
|---|---|---|---|
| 多个方法的单一指标对比（3–12 个） | 横向条形图 | 饼图、3D 柱状 | 饼图无法比较相近值；3D 柱遮挡 |
| 同一方法在不同超参下的表现 | 折线图 | 柱状图 | 柱状看不出连续趋势 |
| 训练过程 / 迭代曲线 | 折线 + 阴影（均值 ± 标准差） | 只画均值单线 | 没有方差带就看不出稳定性 |
| 两两方法的胜负关系 | 散点（x=A 分数，y=B 分数，对角线上方=B 更好） | 并列柱 | 散点一眼看出谁赢多少 |
| 分布比较（多个数据集的分数分布） | 小提琴图 / 箱线图 | 均值柱 | 均值掩盖长尾与异常 |
| 相关性 | 散点 + 拟合线 + 相关系数 | 双轴折线 | 双轴是误导性最强的图之一 |
| 混淆矩阵 / 分类结果 | 热力图（同一色系，标注数值） | 灰度表 | 色阶比灰阶分辨度高 |
| 消融（逐项去掉组件） | 瀑布图或分组条形 | 堆叠柱（除非真要看构成） | 堆叠柱的比较基线在漂移 |
| 效率（速度 vs 精度） | 散点 + Pareto 前沿线 | 两张独立柱状 | 权衡关系必须同框 |
| 多数据集 × 多方法 | 小倍数图（facet 网格，共享轴） | 一张挤满的巨图 | 共享轴才能跨格比较 |
| 排序/排名变化 | 斜率图（bump chart） | 分组柱 | 排名变动是斜率图的强项 |
| 占比构成随时间变化 | 堆叠面积图 | 多张饼图 | 饼图序列无法看出流动 |

## 本套件内置的图型库（19 类，按用途分组）

**比较类**：横向条形、分组条形、斜率图、雷达图（≤6 维，多了就糊）、哑铃图（前后对比）
**趋势类**：折线、面积、堆叠面积、双轴（慎用）
**分布类**：小提琴、箱线、蜂群（点+分布）、直方
**关系类**：散点、气泡（三维：x/y/大小）、Pareto 前沿、热力图
**构成类**：堆叠柱、瀑布、树图

## 三个必须提醒用户的坑

1. **双 y 轴**：两条线的交叉点由轴的缩放决定，可以被任意制造。除非两条线有物理关联，否则拆成两张图。
2. **截断 y 轴**：从非零起点画柱状图会放大差异。柱状图必须从 0 起；折线可以截断但要标出断点符号。
3. **误差棒缺失**：单次运行的柱状图没有误差棒，审稿人会直接质疑。要么多次运行给方差，要么在图注里写明是单次结果。

## 输出格式要求

- 矢量优先（PDF/EPS/SVG），位图 ≥300 dpi。
- 字号与正文一致（缩到单栏后不小于 7pt）。
- 同一篇文章内所有图的配色映射保持一致（方法 A 永远是同一个颜色）。
- 色盲友好：避免红绿对立，用蓝橙或加形状区分。

## 给用户的产出格式

```
建议图型：[名称]
画法：[x 轴 / y 轴 / 分组 / 误差表示]
必须标注：[单位、样本量、显著性标记]
不要用：[替代方案] 因为 [原因]
若数据是 [某种形态] 则改画 [另一图型]
```

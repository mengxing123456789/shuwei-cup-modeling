# 实验分析：把表格讲成论证

## 为什么会写成流水账

典型失败段落：「表 2 展示了各方法在三个数据集上的结果。我们的方法在数据集 A 上取得 85.2，比 baseline 高 1.5；在数据集 B 上取得 78.3，高 0.9；在数据集 C 上取得 81.1，高 2.0。这说明了我们方法的有效性。」

三个病：结论在最后且空洞；每个数字平铺没有主次；「说明了有效性」是同义反复。

## 模板

```markdown
# Role
你是负责撰写实验章节的资深研究者，擅长把结果表格转成有论证链的正文。

# Task
基于【结果表 / 指标清单】，写出【结果段 / 消融段】的英文正文。

# 输入
- 表：TABLE（含列名、行名、单位、是否多次运行）
- 要证明的论断：CLAIM
- 对照方法：BASELINES
- 关键设定：SETTING（预算、参数量、训练数据量）

# Constraints
1. 结构：结论先行 → 证据（数字 + 对照 + 幅度换算）→ 机制解释。
2. 数字使用：
   - 只能使用表中出现的数字，不许推算、不许估计。
   - 幅度必须换算成读者可感的量：绝对分差、相对百分比、参数量/FLOPs 比。
   - 无显著性检验时不用 significant / significantly，用 higher / outperforms by。
3. 主次：最能支撑论断的两三组数字先说，其余用一句话概括范围（"consistently across the remaining five benchmarks"）。
4. 解释：机制层面一句；无法解释时写与某假设一致，不编因果。
5. 消融：每个去掉的组件说明其职责，按掉点幅度降序。
6. 禁词：state-of-the-art 除非有第三方榜单；remarkable / impressive / promising 这类评价词。
7. 载体：LaTeX 纯净，% _ & 转义，$...$ 原样，不加粗。

# Output
Part 1 [LaTeX]：分析正文（一段或两段）
Part 2 [数字溯源]：每个数字 → 表名 + 行 + 列
Part 3 [论证自检]：论断是否被证据闭合；哪一处证据最弱

# Self-check
- 有没有出现表里没有的数字？
- 有没有用 significant 但没有检验？
- 第一句是不是结论而不是"表 X 展示了"？
```

## 幅度换算速查

| 原始表述 | 改写成 |
|---|---|
| 85.2 vs 83.7 | 高出 1.5 分（相对提升 1.8%） |
| 同样的分数但参数少一半 | 以 48% 的参数量达到同等精度 |
| 三个数据集都高 0.5–2.0 | 在全部三个基准上一致领先（+0.5 至 +2.0） |
| 训练快 3 小时 | 训练时间缩短 31%（9.7h → 6.7h） |
| 1.2 分但 baseline 是复现的 | 相对复现 baseline 高出 1.2 分（原论文报告值见脚注） |

## 消融段的固定写法

```
去掉 COMPONENT 后 METRIC 下降 X（幅度），说明它主要负责 FUNCTION。
进一步把 COMPONENT 换成 ALTERNATIVE，下降 Y，说明收益不来自参数量的增加。
```

第二句是关键：只去掉组件会被质疑「是不是只是少了参数」。必须有一个等参数量的替代对照。

## 最弱证据的三种典型

1. **单次运行**：没有方差，任何微小差距都不可信。修法：多次运行给均值±标准差，或明确标注单次并在结论里弱化差距。
2. **未复现的 baseline**：引用原论文数字但训练设定不同。修法：注明来源与设定差异。
3. **只在自家数据集上领先**：修法：至少一个公开基准，或明确声明这是领域特定设定。

## 验收

- [ ] 每个数字可溯源到表的具体单元格
- [ ] 无 significant / state-of-the-art / remarkable
- [ ] 首句是论断
- [ ] 消融有等参数量替代对照
- [ ] 最弱的一处证据已在 Part 3 明确指出，而不是藏起来

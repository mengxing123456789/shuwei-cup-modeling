# `shuwei/` — 早期抓取脚本

2023 / 2024 / 2025 三年赛题与获奖论文的抓取、清点、生成脚本。**历史存档，不是流水线的一部分。**

## 每个脚本干什么

| 脚本 | 用途 |
| --- | --- |
| `fetch2023.py` | 抓 2023 年第九届题面与附件 |
| `p2023{,b,c,d,e}.py` | 2023 年 A–E 五题的分题处理（提取题面文本、整理附件） |
| `p2025{b,c}.py` | 2025 年 B/C 两题的处理 |
| `inventory.py` / `inventory.json` | 清点已抓到的文件，产出清单 |
| `scan_ids.py` | 从获奖名单里扫出论文 ID |
| `titles.py` | 抓论文标题 |
| `mk.py` / `readme.py` / `writeall.py` | 生成 `corpus/` 早期版本的目录与 README |
| `check2.py` / `check2024.py` | 校验抓取结果（页数、字符数） |

## 为什么还留着

`corpus/` 里 2019–2025 的语料就是这些脚本抓下来的。将来赛题官网改版、链接失效时，看这里能知道当初是从哪个 URL、用什么规则抓的（每个脚本顶部有 URL 常量与选择器）。

## 为什么不删

删掉不影响任何功能——`corpus/` 是成品，`mmkit/corpus.py` 只读 `corpus/`。留着的唯一理由是**可追溯**：如果 `corpus/` 里某份文件内容可疑，能顺着这里找到原始来源。

## `_src/` 子目录

`shuwei/_src/{2023shuwei,2025autumn,Shuwei2025B}/` 是三个第三方 GitHub 仓库的克隆（含各自的 `.git`），已在 `.gitignore` 里排除，**不进仓库**。它们是抓取时参考过的开源实现。

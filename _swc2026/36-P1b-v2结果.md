## 2. 协议（先写死再训练）

- 数据：`data/state.npz`（66070 帧 / 69 记录；每只手 32 维手部状态 + 8 维几何 + valid 位 = 82 维 ×2），
  划分用 `panel_records.csv` 的 group split，**按记录分组**：train 55 记录 / validation 7 / test 7，样本 46276 / 6685 / 12143。
- 窗口：因果窗（只用当前帧及以前，左填充首帧，**不跨记录**）；三尺度 (15,1)/(60,1)/(120,2) ≈ 0.5 s / 2 s / 4 s。
- 选择：每个 (配置, seed) 用 **validation AUC** 挑最佳 epoch；test 每个 (配置, seed) **只评一次**；全程无 test 调参。
- 校准：temperature scaling 的 T 只在 validation 拟合，ECE / P@0.5 / R@0.5 同样只在 validation 定阈值，再原样用于 test。
- 三 seed：20261120 / 20261122 / 20261123；18 epochs，batch 512，`pos_weight≈102.5`，focal / BCE 见表注。
- 参数量 318790（8 个配置共用同一骨干，差异只在视图、损失、正则、增广、TTA）。

## 4. 三个必试方向的结论

### 4.1 多尺度 TCN + attention pooling（有效，作为基座）

V1：每尺度一条膨胀残差分支（dilation 1/2/4/8、GroupNorm(8)、GELU、dropout），池化用「末帧 + 学习注意力 + 时间 max」
三路拼接，再进 MLP 头；辅助头预测 occlusion / near_edge（BCE 权重 0.3）。
相对预注册单 seed 基线 0.067556，V1 三 seed 平均 test AP 0.12573（+86.1%），worst 从 0.7646 抬到 0.77150。

### 4.2 环境对抗 / Group DRO（无效，且明显有害）

V3（GRL，16 个训练环境，类权重 1/√n，λ 从 0 线性升到 0.1）test AP 0.10596、worst 0.65962；
V4（Group-DRO，q_e ∝ q_e·exp(0.5·L_e)，按环境加权采样）test AP 0.06482、worst 0.50744。
两者都建立在 V2 的「记录级归一化」视图上，而该视图本身已经把 worst 打到 0.59469，
域泛化模块没有可救的东西。**结论：在当前数据量下，环境标签只有 16 类、每类 1–8 条记录，
对抗/重加权学到的是「记录指纹」而不是环境不变性，反而抹掉了坏帧真正依赖的绝对位置与画面边缘线索。**

两点必须说清：

1. **温度校准在高 AP 配置上帮了倒忙**：V1 / V8 的 T>1（压低置信度）却让 test ECE 从 0.205 / 0.208 升到 0.247 / 0.246。
   含义不是「校准写错了」，而是 **validation 与 test 的置信度偏移方向不一致**——val 上过自信、test 上并没有那么过自信。
   跨环境部署时，用单一温度把 val 的校准搬到 test 是不成立的。
2. **顶配的绝对校准仍然很差**（ECE≈0.2，P@0.5 只有 0.070、R@0.5 0.551）：因为正例率仅 1.9%，
   模型输出整体偏高。要拿去当「自动丢弃」用，必须按目标误丢率在 val 上重定阈值（本任务只报了 0.5 这一点）。

## 5. 失败原因分析

1. **记录级归一化是死路（V2/V3/V4）**：把每帧特征按本记录均值/标准差标准化，等于删掉了「手在画面里的绝对位置」
   与「离画面边缘多近」——而坏帧的定义正是边缘/出画/遮挡。V2 的 test AUC 从 0.826 掉到 0.701，worst 从 0.772 掉到 0.595。
2. **所有配置的 best epoch 几乎都是 1–3**：validation AUC 在第 1 轮见顶后单调下滑，说明**容量不是瓶颈**，
   16 个训练环境与 4 个验证环境之间的差异才是。继续加参数、加 epoch 只会更快过拟合到训练环境。
3. **18 个正例的环境决定成败**：V5 是唯一在 AP 上单独达标的配置（%.5f），但 seed 20261120 在
   `logistics_0041` 上的 AUC 只有 0.6333，一票把 worst 均值拉到 0.71861。
   反过来 V1/V7 的 worst 稳（0.772 / 0.765）却差 0.004 的 AP。**两指标在这一点上互相拉扯，且都由同一小样本环境放大。**
4. **强正则与 focal 各自只解决一半**：强正则（V5）抬 AP、压 AUC；focal（V6）压 AP；两者相加（V7）回到 V1 的水平。

## 6. 交付配置 V8：为什么是它

V8 = V1 的结构 + 一个**保标签的对称性**：坏帧标签是「任一只手坏」，对左右互换不变。于是

1. **训练增广**：每样本以 0.5 概率把 fl↔fr、gl↔gr、validL↔validR 整列互换（标签不变）；
2. **推理 TTA**：对原输入与互换后输入各前向一次，概率平均（不引入任何 test 信息，纯输入变换）。

效果（三 seed）：test AP 0.14937（逐 seed 0.16194 / 0.15462 / 0.13156，**三个 seed 全部 ≥0.13**），
worst per-env AUC 0.77770（逐 seed 0.77854 / 0.76950 / 0.78506，全部高于基线 0.7646），test AUC 0.82714。
代价：推理多一次前向（≈2×），训练 41.7 s/seed，参数量不变。

直觉解释：训练集里左/右手坏帧的比例、以及「哪只手更常出画」在测试环境里会变；把左右自由度对称掉，
等于把这条最容易随环境漂移的捷径封住，模型被迫学「手的形状/位置是否异常」而不是「是左手还是右手」。

## 8. 局限与下一步

- **worst 只在 2 个环境上取小**，其中一个只有 18 个正例。这条指标的 seed 波动可达 ±0.15，
  单 seed 结论不可用；报告一律给三 seed 均值与逐 seed 值。
- **ECE≈0.2 未解决**：需要的不是更好的温度，而是按环境条件化校准（每环境一个温度）或直接放弃概率语义、只用排序。
- **域泛化没被证伪，只是没被正确实现**：本任务的「环境」粒度是门店，只有 16 类；若要再试，应换成
  记录级/时间段级的伪环境，或在特征层做「位置不变 + 边缘敏感」的显式分解，而不是对 16 类做对抗。

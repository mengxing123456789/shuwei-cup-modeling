MODULE backend.services.paper_submission_contract
DOC: Deterministic release gates for mathematical-modeling paper submissions.

The language-model step is allowed to draft and repair the paper, but it does
not decide whether the abstract/directory contract passed.  These checks run
the authenticated ``shared-scripts`` package used by the current runtime, so a
development checkout and a packaged Capsule validate against their own exact
Skill version.

MODULE backend.services.artifact_graph
DOC: Public artifact provenance and impact analysis.

The graph is intentionally derived from public workspace files instead of
trusting model-authored metadata.  It never descends into protected directories
and never executes user code.  The result powers beginner-friendly actions such
as "modify this chart" while keeping the actual edit bounded to explicit source
files.

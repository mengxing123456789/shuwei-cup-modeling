MODULE backend.services.artifact_patch
DOC: Transactional, target-bounded artifact edits for the chat workbench.

The editor-agent is powerful by design.  Chat mode must never point it at the
real workspace and hope that a prompt is obeyed.  This module runs it in an
isolated copy, verifies the complete filesystem diff, then atomically replaces
only the files the user approved.  Every committed edit has an independent
local version that can be rolled back while its base still matches.

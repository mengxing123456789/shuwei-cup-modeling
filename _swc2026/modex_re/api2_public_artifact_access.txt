MODULE backend.services.public_artifact_access
DOC: Single security boundary for text artifacts exposed to collaborative chat.

The MCP read tools and the server-side evidence prefetcher must use the same
path rules.  Keeping a second, slightly different implementation here would
eventually let one path see private runtime files that the other path hides.

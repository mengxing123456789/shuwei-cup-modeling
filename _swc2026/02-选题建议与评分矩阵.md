## 0 结论（先行）

**建议最终选择 A 题。**

理由三条，每条都能被复查：

1. **A 是四题里证据链最完整的一题：四个问题各有独立、可复算的结果，而且互相咬合。** P1 是一个真解的三维径向耦合求解器（质量守恒相对失衡 **7.66×10⁻⁵**、三档网格 Rp 差 **7.7×10⁻⁶**）；P2 从量纲分析推出 Rp=C·t^0.5，数值解给出 ν=**0.50297/0.50165/0.50080**（R²≈0.999999）；P3 给出每场景 **328–347 点** Pareto 前缘 + 膝点 + NSGA-II 交叉核对（相对差 3.1×10⁻⁴）；P4 用附件C 108 组数据做五种模型比选（AIC/BIC）、按浸泡档整组留出的 5 折 CV（每折 72 训练组/36 测试组）、400 次 bootstrap，并给出 Sobol 全局敏感性 + 弹性解析交叉验证（预测 S1 比 0.227 vs 实测 0.266）。**这不是四篇作文，是一条从方程到钱、再到敏感性的完整链。**
2. **A 有一个别队几乎一定写不出来的"真张力"，而且我们已经把它解成了加分项。** 机理侧的改造半径是 √t 扩散前沿（ν=0.503），而附件C 的产量-浸泡响应是指数饱和（R²≥0.997，τ=7.0/8.5/10.0 d）。我们没有把两者硬凑：Rp(t) 是前沿位置，产量响应是"前沿扫过的体积 × 边际贡献递减"的结果；并用 τ 与 Rp(60 d) 的 log-log 指数 **0.275**（扩散预期 2.0，实测/预期=0.138）证明 **τ 不受扩散控制**，把 τ 归因到滞留/吸附（Kd、aσ、aθ）并反标定。这个"数据否定了最漂亮的假设、于是换一层解释"的过程，正是评奖最看重的科研味。
3. **A 的题目自带一个经济学硬结论，且我们证明它不是算错。** 官方 B.4 检验向量 **848.25 万元**用脚本断言 PASS（误差<0.01），经济模块正确；在这个正确口径下 Case1/Case2 结构性亏损（Case1 峰 **−720.21 万元**，EUR 只有 224.7 m³，要转正需 2586.6 m³ = **11.5 倍**，或油价涨到 **35,417 元/m³** = 10.4 倍；**单靠压裂成本下调不可能**，所需 Cfrac 为负 600 万元），Case3 可盈利（峰 **+184.26 万元**，ts*=35 d，仅需观测产量的 0.805 倍即盈亏平衡）。"什么条件下这个项目不成立"是可发表的结论，不是失败。

**修订记录（三段）**：预登记 A>B>C>D（建模前）→ 中途 **B>A**（当时 A 的两层接口没做出来，A-1 是真实裂缝）→ 终评 **A>B**（A 的求解器、CV、Sobol 与 τ 归因全部落盘，A-1 从"裂缝"变成"发现"）。每次改判的依据见 §7。

B 仍是**第二选择**：它是四题里最"干净"的一题（全部闭式/精确、双实现复现、零数据依赖）；若评委偏好纯几何与调度，或只剩 3 小时成稿，B 更稳。C 与 D 不作最终选择，理由在 §2.3、§2.4。

**创新点候选**：①三场耦合方程的无量纲化 + 无量纲群量级表 + 由量纲分析导出浸泡-改造半径关系；②把"改造半径的扩散前沿（√t）"与"产量的有效响应（指数饱和）"拆成两层并给滞留/吸附接口——**这是 A 题唯一能同时满足机理与数据的写法**；③由 τ 与 ts\* 得到可检验判据：**ts\*/τ > 2 时 τ 主导敏感性，否则幅值参数与浸泡成本主导**（实测弹性比 0.227/3.31/6.52 vs 实测 S1 比 0.266/3.03/6.54，误差 <17%）；④数据驱动的**结构性亏损**判定与盈亏平衡反推（Case1：rev 67.7 万 vs cost_pv 787.9 万，需 EUR 2587 m³=11.5 倍 或 油价 35,417 元/m³；Cfrac 所需为负 → 降成本无解）。

**风险（A-1…A-4，终评后更新状态）**：

- **A-1 机理与数据形状不一致 → 已解成"两层响应"，但叙述仍是最大风险**：ν=1/2 的 √t 标度对数据只有 R² 0.68–0.82，指数饱和 ≥0.997。处置：Rp(t) 只负责"前沿位置"，产量响应另设 r_eff=r∞(1−e^{−t/τ})，τ 由数据反标定，并用 τ–Rp 的 log-log 指数 0.275（扩散预期 2.0）证明 τ 不受扩散控制。**正文绝不能写"√t 与数据吻合"**；必须把两张 R² 都摆出来（这是证据，不是家丑）。
- **A-2 单井单缝口径下的结构性亏损**：Case1 在给定价格与成本结构下不可能盈利；黄金向量 PASS 证明经济模块正确。盈亏平衡反推（`p4_econ:break_even`）：Case1 需 EUR 2586.6 m³（观测 224.7 的 **11.5 倍**）或油价 **35,417 元/m³**（10.4 倍）；Case2 需 2714 m³（**2.13 倍**）或油价 6840（2.01 倍）；**两场景所需 Cfrac 均为负值（−600 万/−325 万），即降低成本无法转正**。A.3 表已给定 Lf/hf/wf 与 kf，缝面面积是给定值不是自由参数。
- **A-3 附件C 的划分合规**：整组划分、测试集含未见浸泡档、禁同组内切相邻日——已用 `split_audit` 留证据（每折 72/36、test_ts 全不在 train），可复查。
- **A-4 时间成本**：四问代码全部跑通（P1 求解器、P3 Pareto 328 点、P5 18432 次评估），剩余是 25 页英文成稿与图表整合，约 4–5 h。

## 4 为什么不是其他三题（每题一句 + 一个数字）

- **B**：它是四题里最干净的一题（闭式下界 14.36 cm 可达、最大观测开始 11.2141 s、s_max=66.92 m、a+80b≤1.6384），但**题面不提供任何数据**，四项全是几何与调度，25 页里能装的内容只有 A 的一半；且"几何题看起来简单"的第一印象需要三条非显然结论去扳，容错低。它是最稳的备选，不是上限最高的选择。
- **C**：题面依赖的五个评估文档在下载包里不存在（`record_index.csv` 等零命中），P3 还要在 `terminal_on_invalid=true` 下复刻隐藏协议；S3 满服务成本 46.5 > 预算 40，必须主动弃 job，与"η≥0.50"的硬门槛正面相撞。
- **D**：题面要求的结论（各向同性均匀环 → 单一中心）在严格处理下只能降格为"条件成立"，而三条反例（阻力介质、单共振带、慢混合）都会写成"题目结论不成立"；这不是严谨度问题，是评分口径问题。

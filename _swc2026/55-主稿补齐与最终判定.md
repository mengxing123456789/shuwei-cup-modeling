## 2 补齐 ε / solver-fallback：不是写一段话，是补一个真实验

新增 `code/up21_p2_cost_sweep.py` → `data/up21_p2_cost_sweep.json`：在实测的 ridge 误差曲线上，把定价规则

```
J(T) = R(T)[cm] + λ·(C0/T + C1)
```

对 **C0 ∈ {0.10,0.25,0.50,1.00,2.00} × C1 ∈ {0.05,0.10,0.20,0.40} × λ ∈ {0.25,0.50,1.00,2.00,4.00} = 100 个系数三元组** 重新求解（网格 0.20–1.00 s、步长 0.05 s，与 `code/p2_predict.py` 同一网格、同一 measured domain，所以 baseline 格逐位复现 0.30 s / 4.5212）。

| 量 | 值 |
|---|---|
| 三元组数 | **100** |
| 最优点落在内部 | **56**（56%） |
| T\* 跨度 | 0.20 → 1.00 s（**0.80 s**） |
| 只动 C0 | 0.20 → 0.65 s（**0.45 s**） |
| 只动 C1 | **0.00 s**（不动） |
| 只动 λ | 0.20 → 0.65 s（**0.45 s**） |
| 与 baseline 相差 ≤0.05 s 的格 | 20% |

正文 §4.4 据此改写为「re-solve the priced rule on 100 coefficient triples: interior in 56, spans 0.20 to 1.00 s, moves 0.45 s across the charge for a look while the per-second term moves it by 0.00 s」。

**solver fallback** 一句也写进 §5.2：「We do not solve a mixed-integer program for this objective: a solver needs a fallback for the infeasible instances the budget and horizon create, and its answer would depend on that fallback. The rule has no solver, so no fallback, and every reported trial is admissible by construction.」—— 这是**用「没有 solver」回答「fallback 多少次」**，比报一个 fallback 次数更强。

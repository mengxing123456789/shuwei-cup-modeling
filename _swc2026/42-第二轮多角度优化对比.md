## 1. 执行方式

七个方向各派一个子代理，文件作用域互不重叠：

- 只写各自前缀的 `code/up2_*`、`data/up2_*`、`logs/up2_*` 与对应报告；
- 不修改 `main.tex`；
- 每个方向在训练前把门槛写进脚本（预注册）；
- 验证集选超参，测试集只评一次；
- 不达标也如实记录，不以失败为由删实验。

## 3. 各方向的关键证据

### P1-a：解码器升级只改善边界精度
- C1 解码器：测试 ARI **0.5723**、B-F1 **0.1408**；v1 为 0.5806/0.1200。
- 多任务 TCN（C2）0.5475/0.0311；SSL+多任务（C3）0.5860/0.0729；集成（C4）0.5511/0.0633。
- 结论：val→test 排序反转，b-F1 的瓶颈在分数定位；只把 C1 作为附录 L 的一行，不替换正文主模型。

### P1-b：V8 是真正的双门槛通过
- 三 seed AP：0.16194 / 0.15462 / 0.13156，全部 ≥ 0.13。
- 三 seed worst per-env AUC：0.77854 / 0.76950 / 0.78506，全部 ≥ 0.764637。
- 校准无效：温度缩放后 test ECE 从 0.205/0.208 升到 0.247/0.246；预注册写明“按 val AUC argmax”会选 V1（0.8654 vs 0.8608），但 V1 不过 AP 门槛，故联合门槛选 V8。

### P1 状态：多任务 TCN 最强，组合反而退化
- C 臂：AUC **0.8325**、AP **0.1056**、per-env 0.7855/0.8913、512,387 参数、134.6 s。
- D 臂（平滑+残差+辅助头）：AUC 0.8222、AP 0.0924；比 C 低 0.010 AUC / 0.013 AP，说明三类增益不叠加。
- 基线 fused：AUC 0.6267、AP 0.0407。

### P2：最大单项收益是修 bug，不是新模型
- D 臂 L30：RMSE **5.686 cm**、q90 **9.163 cm**、coverage 0.893，仍未过 5.50/9.00。
- 最大单项变化是 v1 特征的手性通道翻转：归一化后同一个 ridge 从 L30 6.314→**5.766 cm**（−8.7%），L6 2.006→**1.053 cm**（−47%）。
- 决策层：J 从 4.521（ridge）降到 **3.574**（最好臂），最优观测时刻仍是 0.25 s。
- 结论：P2 不替换正文主模型；记录为“架构搜索未过门槛 + 手性 bug 修正”。

### P3 策略：+5.38 点是真实增益
- 冻结规则：S2 `A_s0_rabs_q0.45_g0.75_l12_m0.60_G0.00_k0.60_0.60`；S3 `A_s0_rfix_q0.30_g0.35_l20_m0.15_G0.25_k0.60_0.60_rev_t0.02`。
- 修正协议（`C=s+p`、`t=s+max(p,b)`）下：S2 0.7683→**0.8283**（+6.00 点），S3 0.7425→**0.7900**（+4.75 点）。
- blocked 配对差 **+5.38 点**，95% CI **[2.57, 8.18]**；10 个 (case×映射) 块 9 正 1 零（零的那块基线 0.9917，已饱和）。
- 重要勘误：早先报的 +6.96/CI[4.61,9.31] 是 test 切片误用 `[15:20]`（val 段）的污染数，已废弃；正确数字为 +5.38/[2.57,8.18]。

### P3 复核：不是预算问题，是代数问题
- 270 格：0/270 通过 primary，0/270 通过 holdout；最好格 **0.000 点**（等于不复核）。
- 17 个贪心复核格显著有害；`review_greedy` 平均 **−5.70 点**（S1 −2.05 / S2 −6.83 / S3 −8.23）。
- 机制：预约误差 `b−p = α(Q_res−ε)` 把点预测消掉，复核只能压残差宽度（0.4–0.7 s）；每次复核吃掉 100–125 s 时域里的 1 s，边际代价约 0.8 点/s。
- 免费完美 1.0 s 前缀上界仅 **+0.42 点**，低于 1 点门槛；因此负结果不是预算/实现不足。

### 官方口径：0.5487 不是官方基线
- `published baseline ARI 0.5487` 溯源为 `data/p1a_segmentation_compare.json` 的 `ari.gpu_mean`（我方 bi-TCN 臂）；同一规则在 `up_p1a_baseline_check` 为 0.5487、`up_p1a_final` 为 0.5355，差 0.0132 未解释。
- P2 官方主指标是 mean 3D distance R，不是 RMSE；按官方口径 ridge 只在 L=18 显著优于 hold，分位 GRU 在 L=6/18/30 显著优于 hold、L=60 显著变差。
- P3 官方 11 项指标原 pipeline 覆盖 8 项，补 `invalid_actions`、`valid_protocol`、`observations`；450 trials 全部 clean。

## 2. 三条必试方向的实际结果

### D1 有限时域 MDP / 值迭代（何时点复核）

状态 `(m, u, k)`：`m` = 候选相对次优的收益差（残差 sd 单位），`u` = 已付的预测前缀阶段（0/1/2），
`k` = 剩余派单纪元。递推：

```
V[k,u] = max( Φ(m),                         # 立即派单：排序正确的概率
              E_ν[ V[k-1,u+1](|m+ν|) ] − λ ) # 复核：花掉 1 s 时域（k→k-1）+ 持有成本 λ
```

ν 的后验 sd 取先验的 0.7071（多一次观测，不确定性乘 √½），`Φ` 为标准正态 cdf。
后向归纳得到的阈值 `m*(k,u)`（λ=0 / λ=0.03）：

| k\u | 0 | 1 | 2 |
|---|---|---|---|
| 6（λ=0） | 0.95 | 0.70 | —（前缀用尽，派单） |
| 6（λ=0.03） | 0.70 | 0.50 | — |

即：**只有**当排序收益差小于约 0.5–0.95 个残差 sd 时才值得复核，且时域越短阈值越低。
λ 在 tune 段选出的是 **λ=0**（最激进的一档），DP 臂的触发率仍只有 **0.02 次/试验**，
配对差 **0.000 pt**（18 格里 17 格恰为 0，1 格 −0.21）。

结论：**这个 MDP 的最优策略就是"几乎不复核"** —— 不是阈值没调好，而是"复核的期权价值 < λ·1 s"。

### D2 事件触发策略（只在特定窗口内复核）

四个窗口族，阈值全部在 tune 段选：`window_tight`（预测 slack ∈[−1,+2] s、压力 ≤0.95、每单 ≤1 次）、
`window_wide`（slack ∈[−3,+6] s、每单 ≤2 次）、`window_hard`（slack ∈[0,1] s、压力 ≤0.90、bar 0.05）、
`priority_tight`（高权重 ≥1.5×均值 且 slack ∈[−2,+0.5] s、每单 ≤2 次）。

四族的触发率全部是 **0.00 次/试验**，配对差 **0.000 pt**（CI 退化到 [0,0]）。
原因不是窗口太窄，而是**外层 VoI 闸门本身几乎不通过**：在 α=1.0, β=0.5 的headline映射下，
最优候选的加权准时增益 `w_j·(p1−p0)` 在 **>99.9%** 的决策点上不超过 `REVIEW_BAR=0.02`。
四族窗口只是这个零测集的子集，所以都是空臂。

### D3 信息价值上界（完美二次观测的 oracle VoI）

为了把"上界"钉死，另做一组**免费、瞬时、无预算限制**的前缀替换探针（`up2_p3review_probe.py`）：
在 t=0 直接把预测换成更晚的前缀（6=60%、10=100%），**不付 1 s、不付 1 分成本**，同一套规则、同一种子。

| 臂（免费） | S1 最大 Δ | S2 最大 Δ | S3 最大 Δ |
|---|---|---|---|
| free6（0.6 前缀） | +0.42 pt | **+2.50 pt** | **+2.71 pt** |
| free10（1.0 前缀） | 0.00 pt | **+0.28 pt** | **+0.42 pt** |
| true（真实时长） | +5.63 pt | +9.86 pt | +10.52 pt |

- **free10 就是任何付费复核策略的信息上界**（信息超集 + 零延迟 + 零成本），最大 **+0.42 pt**；
- 付费臂 = 同一个信息集合 **再减掉 1 s 时域和 1 单位预算**，因此严格劣于 free10；
- 只有**真实时长**（true）能拿到 +5.6…+10.5 pt —— 那不是"再看一眼"能给出的信息，是另一类知识；
- free6 的 +2.5/+2.7 pt 是**免费**杠杆（改预测前缀），且在 q 上**符号翻转**（S3 q=0.60 时是 −2.08 pt），
  只能当"校准杠杆"研究，不能算复核收益，更不能在 test 上调 q。

⇒ **信息通道的上界 0.42 pt < 1.0 pt。** 任何只用"二次观测"的复核策略在此模型里都不可能达标。

### D4（附加）价格通道的直接测量：贪心复核

既然信息通道封顶，就测价格通道的量级：`review_greedy`（只要还能复核就复核，最激进的火力）。

|---|---|---|---|

18 格全部为负，17 格 CI 上界 < 0 —— 显著有害。**价格（1 s 闲置 + 1 单位预算）是主导项，量级 −2…−10 pt。**

### D5 机制分解：Δ总 = Δ信息 + Δ价格

设计了一个 `placebo` 臂：**照付 1 s 和 1 单位预算，但不更新任何预测**。于是

- Δ价格 = placebo − 不复核；
- Δ信息 = myopic − placebo。

全 18 格平均：**Δ信息 = +0.012 pt，Δ价格 = −0.023 pt，Δ总 = −0.012 pt**。

⇒ 复核的信息收益**确实存在但只有万分之一个百分点量级**，价格项吞掉它。这与 D1/D3 完全一致：
信息只在**残差分布宽度**上起作用，而残差 sd 只有 0.4–0.7 s，排队/排序的粒度远大于它。

## 3. 机制解释（为什么必然 < 1 pt）

**(a) 代数消去：点预测在预留误差里被约掉。** 模型里预约完成时刻 `b = α(pred + Q_res) + β`，
真实完成 `p = αd + β`，所以

```
b − p = α·(Q_res − ε)
```

`pred` 不在里面。复核更新的是 `pred`（点预测）与前缀残差分布；它对"这单会不会迟到"的作用
只能通过 `Q_res` 的**分布宽度**进入，作用量级 ~ Δσ/σ，而不是 Δpred 的 0.69 s。这就是"信息通道只有 0.42 pt"的算术来源。

**(b) 价格是一阶项。** 每次复核吃 1 s，而时域只有 100–125 s（S1/S2 100 s，S3 125 s）；
被复核那一单的准时率对延迟的边际代价是 `φ(δ/σ)/σ`，在 δ≈0、σ≈0.5 时约 0.8 pt/s —— 一次复核的
代价就是近 1 pt，与"上界 0.42 pt"对比，**符号必然是负**。

**(c) 触发事件本身是零测集。** 现有 VoI 闸门要求 `w_j(p1−p0) > 0.02`。12 单里 `w_j≈0.083`，
于是要求 `p1−p0 > 24 pt`；而前缀前进一格对单均准时概率的改变通常只有几个百分点。
所以"值得复核"的决策点几乎不存在 —— 35/90 格曾"触发过"是因为那是在 15 组 α/β 上凑出的少量种子，
在 headline 映射上触发率是 0.02 次/试验（闸门在 q=0.70 × 5 组 α/β × 3 case 上 `max|Δ|=0`，
另在 S2 q=0.30 / S3 q=0.60 / S3 q=0.70 三格抽查与原引擎逐位相同、`max|Δ|=0`）。

**(d) 因此**：复核在本模型里是一个**零价值期权（worthless option）**——
既不能显著改善，也不该被写成改进项；它唯一显著的效果是**被用多了会掉 2–10 pt**。

## 5. 对论文 P3 章节的处置建议

1. **不要**把 review 写成"可提升准时率的杠杆"。写成 **零价值期权的机制证明**：
   - 命题 1（代数）：b−p = α(Q_res−ε)，点预测消去 ⇒ 复核只作用于残差宽度；
   - 命题 2（上界）：free10 完美前缀 ≤ 0.42 pt（本文件表格即证据）；
   - 命题 3（价格）：贪心复核 −2…−10 pt、CI 上界 < 0 ⇒ 多用必亏。
2. **1 pt 不可能来自复核**。若正文需要 ≥1 pt 的改进叙事，唯一被本实验支持的方向是
   **时长模型/校准**（free6 免费臂在某些 q 上 +2.5/+2.7 pt），但它在 q 上符号翻转，
   只能在 train/val 上定 q，且必须声明"这不是复核的功劳"。
3. oracle gap（+3.33/+3.85 pt，来自 `data/p3_oracle_same_rule.json`）要**归因给"真实时长知识"**，
   不能说成"复核的价值"；本实验的 free10 已经证明两者相差一个数量级。
4. 预注册 FAIL 要如实写进正文/附录（与 P0 口径一致：adaptive/oracle 对象不许混写）。

## 7. 两个坑（踩过，写下来）

1. **`code/p3_oracle_same_rule.py` 不能在 import 时被引入**：它 import 时会执行对
   `p3_improved_verify.py` 的补丁。本次一律读它的 JSON，不 import。
2. **值迭代的 `u` 循环必须降序**：先算 `V[k,u_max]`（前缀用尽→派单），再 `u=u_max−1…0`；
   若升序，`V[k,u+1]` 还是 0，`rev = −λ`，结果会假报"任何 λ 都不复核"。本次首跑踩到，
   修正后 `m*(6,0)` 从 0 变成 0.95（λ=0），结论方向不变但阈值有了意义。

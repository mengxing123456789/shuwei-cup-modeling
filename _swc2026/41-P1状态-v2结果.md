## 1. 任务与门槛

目标：在 `panel_records.csv` 的 environment split 下，把 P1 可靠性模型从现有
test AUC ≈ 0.596 / 0.627、AP 0.0407 提升到：

| 门槛 | 要求 |
|---|---|
| test AUC | ≥ 0.70 |
| test AP | ≥ 0.08（prevalence 0.018871，AP 需约为随机的 4.24 倍） |
| per-env AUC | 每个有正例的 test 环境均 ≥ 0.60 |

评价口径与 `data/p1_reliability.json` 完全一致：hand-frame 行，test n = 24,482，正例 462，prevalence 0.018871；test 的 426 个正例在 `logistics_x_courier_station_0011`，36 个在 `..._0041`；`retail_x_supermarket_0078`、`..._0159` 无正例，per-env AUC 记 NA。

## 5. 各方向贡献与失败原因

- **① 时序平滑（A）**：双向 EMA 把现有 fused 分数从 test AUC 0.6267 提升到 0.6496（+0.023），0011 从 0.5281 提升到 0.5695；说明 bad 连续段（均值 6 帧、最长 57 帧）确实有可利用的时间连续性，但平滑只能整理已有信号，无法补出 0011 缺失的判别力，离 0.70 仍差 0.050。
- **② 下一帧残差（B）**：6 个自监督残差 + 逐记录归一化几何，把 hand-level test AUC 做到 0.7889（0011 0.7033、0041 0.9813），AUC 过门槛；但 AP 只有 0.0517（<0.08），说明高分端的排序精度不足，单独作为可靠性分数不合格。
- **③ 多任务 TCN（C）**：本报告最强臂，test AUC 0.8325、AP 0.1056，0011/0041 均 ≥ 0.785；辅助头 test occlusion AUC 0.783（226 正例），near-edge AUC 0.809（只有 5 正例，数值参考意义有限）。相对基线 AUC +0.206、AP +0.065，且没有靠牺牲 0041 换 0011。
- **①②③ 组合（D，主臂）**：test AUC 0.8222、AP 0.0924，0011 0.7473、0041 0.9572，过全部预注册门槛；但相对 C 反而低 0.0103 AUC / 0.0132 AP，0011 低 0.038、0041 高 0.066。**组合并未相加**：逐记录归一化可能抹掉了 0011 依赖的绝对尺度线索（palm_width / bbox_vol），残差特征主要帮到 0041。结论按预注册保留 D 为主臂（它过门槛），但生产中若要单一最强模型，C 更优；D 作为“跨环境更均衡”的备选。
- **D 未平滑时** test AUC 0.7996 / AP 0.0954；双向 EMA 把 AUC 提到 0.8222，但 AP 略降到 0.0924（平滑改善排序、轻微压平高分端）。该权衡在 validation 上已按 AUC 选 α，未见 test 泄漏。

## 6. 校准与不确定性

- ECE15：A 0.0099、B 0.0022、C 0.0066、D 0.0081（均为 validation 拟合 Platt/温度后 test 评估）。数值小主要因为正例极少、分箱后每箱样本少；不应据此宣称概率“精确”，只能说明没有系统性高估/低估。
- 单 seed（20261120）结果；C/D 的 best epoch 都是 1（与既有 p1b 结论一致：容量不是瓶颈，早停点极早）。没有做多 seed 均值，报告中的 C/D 差异不应视为统计显著。
- 0078/0159 无正例，未参与 per-env 判断；per-env 只覆盖 0011/0041。

## 8. 结论

**P1 v2 达标。** 预注册主臂 D_full_v2：test AUC 0.8222 ≥ 0.70、AP 0.0924 ≥ 0.08、per-env 0.7473/0.9572 均 ≥ 0.60，gate **PASS**。四个方向都做了独立训练/评估：时序平滑 +0.023 AUC、下一帧残差把 0011 拉到 0.703、多任务 TCN 单独最强（0.8325/0.1056），三者组合 D 过门槛但未超过 C。后续若要继续冲 AP，优先沿 C 的辅助头/类别不平衡权重调，而不是继续叠加 D 的归一化残差。

## 4. 由此推出的统一因果链（论文主线的候选）

```
前缀几乎不携带 d 的信息（MAE ≈ 0.75 × median，Spearman 0.2–0.5，bias +1.5~2.9）
        ↓
再观测只是发更长前缀 ⇒ 不能降低 σ_d，却实付 1.0 成本 + 1.0 s 延迟
        ↓
P3 再观测净效应为负（S2 −0.0069 / S3 −0.0073）
```
```
p = α·d + β（确定性） ⇒ σ_p = α·σ_d
        ↓
α 越大，同样的 d 误差被放大越多，概率预留才越值钱
        ↓
risk_fusion 增益随 α 单调：S2 +0.003→+0.032，S3 +0.017→+0.055
且 α=0.75（服务时间最短最确定）时反被 slack_old 反超 −0.018/−0.019
```
```
EDF 只用 due_s，完全不吃 d 的分布 ⇒ S2 0.5625 / S3 0.5219 垫底
容量感知 slack ⇒ 0.8153 / 0.7406（+0.253 / +0.219）
```

**一句话主线**：瓶颈不是模型容量，是**时长的信息不可约性**；所以正确做法不是堆模型，而是（a）给出**校准过的时长分布**而不是点估计，（b）让调度器吃分布、并按 α 显式定价预留，（c）承认再观测在这条信息链里没有收益。

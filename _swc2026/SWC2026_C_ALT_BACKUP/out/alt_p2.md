# 备用 P2：三维常速度卡尔曼滤波 + VOI 观测调度

> 本模块与主稿 P2 的 ridge + 共形预测 + 固定 T* 阈值**方法不同**：状态空间模型 + 后验方差驱动的观测调度。面板由 `code/alt_p2_data.py` 从原始数据构建，所有数字由 `code/alt_p2_kalman.py` 一次运行产出，原始数据只读。

## 1 方法

**状态**：21 个 MediaPipe 关键点，每个点 3 维位置 + 3 维速度，共 126 维；坐标统一变换到头部坐标系 `p_h = R(q)^T (p_w - H)`，与主稿 `state.npz` 的头部特征逐位一致（已验证首帧 wrist = `[0.3752, 0.0441, -0.038]`）。

**动力学**（阻尼常速度，CV 的推广）：

```
x_{t+1} = x_t + dt * v_t
v_{t+1} = alpha * v_t + w_t,      w_t ~ N(0, q I)
y_t     = x_t + e_t,              e_t ~ N(0, r I)
```

`alpha=1` 退化为教科书常速度模型；本数据上验证集选择 `alpha=0.6`。阻尼项不是靠「速度自相关衰减很快」选的：训练集实测 lag-1/2/3/5/10 = 0.940/0.905/0.897/0.875/0.817（JSON `model.velocity_autocorr`），到 lag-10 仍很高，所以纯常速度在最短掩蔽档仍有竞争力（0.2 s 上 cv 2.914 对 Kalman 2.862 cm）。选 `alpha=0.6` 是验证集上的长掩蔽表现：纯 CV 在掩蔽超过 0.4 s 后持续外推，阻尼抑制了这一点。旧稿这里曾硬编码 0.878/0.519/0.220/-0.013 一组与 JSON 不符的数字，已按 `model.velocity_autocorr` 修正。

**简化**：`Q` 与 `R` 取对角，63 个坐标各自独立滤波，不估计 63×63 跨关键点协方差。这样矩估计有逐坐标闭式、参数量只有 126 个，代价是不利用手指之间的相关性；若改用 full covariance，仅一个 63×63 协方差就有约 2000 个自由参数，而测试集只有 7 条记录，不足以支撑。

**噪声拟合（矩估计）**：对训练集主导手逐坐标计算 `q_j = Var(v_j)(1-alpha^2)`，`r_j` 取二阶差分平方的 10% 分位除以 6（抑制真实加速度污染）。q 中位数 0.00965，r 中位数 1.624e-09。EM 在本数据上退化到 `r→0` 且 RTS 方差越界，故改用矩估计；`q,r` 弱可辨识的程度由第 6 节消融给出，不靠叙述。

**掩蔽协议**：前缀固定 0.2 s（6 帧）；掩蔽长度 L∈{0.2,0.4,0.6,1.0}s（6/12/18/30 帧）；窗口要求 prefix+mask 整段无 `bad` 标注帧；步长 max(1,L/2)，每 split 每 L 最多 300 窗；预测器只读取前缀，掩蔽段真值只在评分时使用。

|---|---|---|---|---|---|---|---|---|

B（买一次）比 A（不买）更差：多 0.4s 前缀只把可用 lead 从 3.0s 压到 2.0s，而延迟 1s 的代价大于前缀带来的信息增益。C（买两次）才把 lead 压到 1.0s，净收益转正。A 只比“最后状态保持”好 0.035 cm（12.377 vs 12.412），说明 3s 外推里速度信息几乎耗尽；C 的收益主要来自把 lead 缩短到 1s，而不是模型外推得更准。这正是主稿“延迟惩罚 > 前缀增益”的同一结论，只是这里由后验 trace 直接算出，不靠回归系数。

## 5 VOI 调度

决策规则：在状态 `(c,h)` 比较立即预测与再付费看一次（前缀 +12 帧，成本 +1，可用 lead −30 帧）。若后验位置方差的 trace 降幅 `Δtr` 大于阈值 `λ`（cm²/成本单位），就购买。本模型两条边际降幅分别为 1158.006 与 1158.005 cm²，因此阈值 `λ*=1158.006` cm² 是分界：聚合层面低于它买满 2 次，高于它一次不买。按后验 trace 折算的 RMSE 降幅约 1.608 cm/次；实测平均误差 A→C 降 2.503 cm（两次合计）。两者不等说明 trace 只反映随机不确定性，不含模型偏差，阈值应视为相对排序而非绝对精度承诺。

|---|---|---|---|---|---|---|---|
| 只看一次 (A) | 12.377 | 14.582 | 0 | 6 | 0.0 | 0.0 | 仅初始 0.2s 前缀（1 次观测），不付费 |

| VOI λ=1737.0 | 12.377 | 14.582 | 0 | 6 | 0.0 | 0.0 | 高于阈值 λ*，不买（与只看一次同终点） |

## 6 消融

| 扰动 | L=0.2s | L=0.4s | L=0.6s | L=1.0s |
|---|---|---|---|---|
| q×2 | 2.862 (-0.000) | 5.656 (-0.000) | 7.095 (+0.000) | 9.464 (+0.000) |
| r×2 | 2.862 (+0.000) | 5.656 (+0.000) | 7.095 (+0.000) | 9.464 (+0.000) |
| alpha=1（纯 CV） | 2.914 (+0.052) | 7.731 (+2.075) | 11.502 (+4.407) | 21.495 (+12.031) |
| alpha=0.5 | 3.005 (+0.143) | 5.753 (+0.097) | 7.165 (+0.070) | 9.477 (+0.013) |

q×2 与 r×2 的最大绝对变化 0.000 cm；alpha 两行的最大变化 12.031 cm。把 q 或 r 单独翻倍，四个掩蔽长度的变化均 < 0.005 cm。但误差不变不等于后验不变：q×2 把 L=1.0s 的 trace 从 1063.9 推到 2127.8 cm²（×2.00），r×2 只到 ×1.000。这说明 q 决定不确定性尺度、r 几乎被吸收；均值误差对两者都不敏感，也解释了为什么 EM 会退化：`r` 在似然里接近不可辨识。

验证集 alpha 选择（7 个 horizon 的平均，q/r 随 alpha 重新矩估计）：0.4→9.152，0.5→9.132，0.6→9.117，0.7→9.133，0.8→9.301，0.9→10.419，1.0→29.936 cm。0.5–0.7 几乎并列，1.0 明显恶化；选 0.6 不是单点最优的过拟合，而是平台区中点。注意消融表的 alpha=1 行固定用 alpha=0.6 的 q/r，只隔离阻尼项；验证集 alpha=1 行重新拟合 q/r（q→1e-7），两者不可直接比较。

## 7 结论

1. 在官方掩蔽协议下，阻尼 CV 卡尔曼在四个掩蔽长度上均优于“最后状态保持”：0.2s -0.53 cm、0.4s -0.34 cm、0.6s -0.26 cm、1.0s -0.09 cm（负值为改进）。但优势随 horizon 迅速缩小：1.0s 掩蔽处 0.09 cm，3s 外推（A）处只有 0.035 cm（12.377 vs 12.412），实际可视为与 hold 持平。真正的可用收益在 1s 以内；3s 外推不应宣称模型优势。
2. 误差几乎由 lead 决定，前缀长度从 0.2s 增到 1.0s 的收益在本模型里为 0：同一决策点、同一 3s 目标下，0.2s 前缀 12.789 cm，1.0s 前缀 12.789 cm，差 +0.000 cm。机制有两层：数据上速度自相关在 0.5s 内衰减到 0.22，纯 CV 外推必然高估持续运动；拟合上 `r→0` 使滤波在决策点几乎完全信任最后一帧，更多历史不再改变状态。第一层是数据事实，第二层是弱可辨识的建模后果，二者都写进了局限。这与主稿 ridge 的“前缀增益远小于延迟代价”方向一致，但机制不同：不是模型容量不足，而是速度去相关 + 观测噪声被吸收。
3. 因此 VOI 在 `λ>λ*` 时不购买、在 `λ<λ*` 时买满两次；不存在“买一次”的内点解。若把 1 成本单位视为硬预算，最优策略是 A（不购买）；若只最小化误差且成本可付，C 最优。

## 8 局限

- Q,R 取对角，逐坐标独立滤波；手指之间的瞬时相关被忽略，这会让指尖误差被高估或低估，具体方向取决于相关符号。
- 只评估主导手；非主导手只用于选择主导手，不进入误差统计。
- 掩蔽协议是官方协议的可见子集：prefix 固定 0.2 s，官方还允许 0.6/1.0 s 前缀；A/B/C 三选项的 lead 分别为 90/60/30 帧，与官方 p2_official.py 的动作空间一致。L 集合按任务指定 {0.2,0.4,0.6,1.0}s，官方 p2_predict.py 另用 {6,15,30,60} 帧，本模块不覆盖后者。
- VOI 的 trace 来自线性高斯后验，协方差与观测值无关：所有记录、所有窗口的后验 trace 只由 alpha、q、r 和 horizon 决定，因此逐记录 VOI 退化为同一条规则，无法体现“某条记录更值得看”的样本差异。
- 噪声参数 q,r 弱可辨识：r 从 1e-9 量级翻倍对误差几乎无影响（见消融），真实观测噪声可能被过程噪声吸收。
- 未做跨被试泛化：split 沿用官方 record_split.csv（train 55 / validation 7 / test 7），测试集只有 7 条记录。
- 没有把误差换算成成本；VOI 阈值以 cm^2/成本单位给出，成本到厘米的换算需要赛题额外给定。

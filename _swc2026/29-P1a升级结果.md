# P1-a 升级结果：验证集选出的解码规则在 test 上只涨 0.021，且 boundary F1 反而下降

**结论先说**：把"逐记录自适应阈值"做完，**门槛未达**（text ARI 0.60 / boundary F1 0.30 都没到）。但这一轮拿到了一个清楚的机制解释，比涨点更有价值：**validation 的段数支撑与 test 不重叠**（val 真实段数 ≤7，test 最大 21），所以任何在 validation 上调的解码超参都在"系统性欠分割"，而 test 的平均段数是 9.6。这不是方法弱，是划分决定的。这是第三次出现同一个失败模式（前两次：k 上限 BIC 选 k=23 → ARI 0.014；分布先验在 S3 反向）。

## 3. test（每条规则只评一次）

| 规则 | 是否 val 选出 | test ARI | 相对基线 | boundary F1 | 平均段数 |
|---|---|---|---|---|---|
| published H0.30 / D54 / s2 | 基线 | 0.5492 | — | **0.1539** | 16.0 |
| **quant q0.85 / s3 / D78** | **是（val 第 1）** | **0.5695** | **+0.0208** | 0.0713 | 10.9 |
| quant q0.85 / s3 / D54 | 否（val 第 5） | 0.5806 | +0.0319 | 0.1200 | 13.3 |

**门槛**：ARI ≥0.60 未达；boundary F1 ≥0.30 未达。**不合格，记为负结果。**

**为什么 test 最优的那个不能当头条**：`D=54` 在 validation 上排第 5（0.5724），在 test 上却最高（0.5806）。若拿它当结果，就是**在 test 上选超参**——这正是我们前两天否掉 `ward_k25 +0.1248` 的理由。所以论文只能报 **0.5695（val 选出）**。

## 4. 逐记录：涨的与塌的都很具体

| rec | 真实段数 | 基线 ARI（段数）| val 选出规则 ARI（段数）| 变化 |
|---|---|---|---|---|
| 17 | 3 | 0.665（2）| **0.459（1）** | **−0.206 塌了** |
| 18 | 3 | 0.877（4）| 0.875（3）| −0.002 |
| 37 | **1** | 0.017（15）| 0.019（12）| +0.002（仍塌）|
| 41 | 9 | 0.588（16）| 0.594（10）| +0.006 |
| 56 | 11 | 0.535（32）| **0.737（19）** | **+0.202** |
| 61 | 20 | 0.552（27）| 0.553（20）| +0.001 |
| 68 | 8 | 0.610（16）| **0.750（11）** | **+0.140** |

**读法**：自适应分位阈值让**长记录**（56、68）的过分割明显缓解，但把**短记录 17** 从 2 段削成 1 段、ARI 直接掉 0.206。净效应 +0.021 是两个方向几乎抵消后的残差。

## 5. 机制（这条要写进论文）

- validation 的真实段数集合 `{3,3,4,6,6,6,7}`（最大 7），test 是 `{2,4,4,9,10,12,21}`（最大 21），**支撑几乎不相交**。
- 因此 validation 只能区分"要不要平滑/要不要稀疏"，无法惩罚"欠分割"——而欠分割恰恰是 test 的主要失效模式。
- 后果量化：`D=78` 与 `D=54` 的差别在 test 上值 **0.011 ARI**（0.5695 vs 0.5806），方向与 validation 相反。**这就是"在 validation 上选解码超参"的转移代价。**
- rec37（1 段、1644 帧）在任何阈值规则下都塌（0.017–0.019）。带惩罚的选择本应救它，但 validation 里没有同类样本可供选 λ，所以 λ 只能靠先验定——这条也如实写。

## 6. 下一步（已被门槛逼出来的唯一正路）

不靠 validation 选超参，而是**在记录内部选**：对每条记录自己拟合 K=1..K_max 的分段模型，用**记录内留出似然/BIC** 定 K（这也正是昨天 `best_p1a_select.py` 的思路，只是当时用在聚类上）。若要继续，这就是下一轮唯一值得做的方向；否则 P1-a 就停在 0.5695，并在论文里写成"解码是瓶颈、但 validation 无法识别该瓶颈"。

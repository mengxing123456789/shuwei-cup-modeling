# `refs/` — 通用参考书

与具体题目无关、但建模时反复要查的东西。只保留了一份 PDF。

| 文件 | 用途 |
| --- | --- |
| `数学建模竞赛中应当掌握的十类算法.pdf` | 十类算法的适用条件与实现要点（规划、统计、机器学习、评价、图论、微分方程、元胞自动机、排队论、博弈、智能优化） |

## 原本这里还有 `contest-code/`

`refs/contest-code/` 是历年赛题附带的参考代码与数据（`.m` 840 个、`.mat` 74 个、`.bmp` 5373 个、`.yuv` 6 个、`.exe` 20 个，合计 73 MB），已从仓库移出：

- `.bmp` 5373 个是视频解码帧，`.yuv` 是原始视频，都属于「原始数据」而不是「参考代码」
- `.exe` 20 个来源不明，不该进公开仓库

需要时从赛题官网重新下载。`mmkit` 里没有任何代码依赖这个目录。

## 加东西的标准

只放**与题无关、可反复查**的资料。具体年份的题面、附件、获奖论文都进 `corpus/`，不进这里。
